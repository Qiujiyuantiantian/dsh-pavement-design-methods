# dsh-pavement-design-methods

《路面设计原理与方法》（第 4 版）的蒸馏插件：**63 张能力卡**，8 个可用章。

## 这不是设计手册

两条硬证据：

1. **两大设计章都没有一次可复现的完整算例。**
   ch7 的 AASHTO 算到结构数 SN=5.0 就停；CBR 最接近但交通只给一个轮载；AI 是验算不是设计；
   Shell 十步全文字零数值；我国七版**只判合格、不给厚度**。
   ch8 唯一成链的是 1958/1966 版，**84/94/02/11 四版一个算例都没有**。

2. **全书唯一一次完整手算，结论是错的。**
   ch8 的 p344：板角 `2.511 MPa` 大于容许 `1.8 MPa`，式内印着「>」，却判「符合」。
   三层错——判定层丢掉比较式、口径层拿板中档卡板角、代算层用 1.8 顶替算出的 1.635。

它交付的是：**这份文件属于哪套方法、参数能不能这么取、这条链走到第几步会断、缺的是哪张表。**

## 第九章丢失

原书第九章「机场道面设计」（印刷 p414–p495）与第八章尾部（p383–p413）在原转录中被替换成
**至少三本无关教材**的内容（「第4章 信号的频域分析」「第四章 电场与电势」等）。已查实并隔离，
**不补编**。详见 `skills/pavement-design-methods/BOOK-MAP.md`。
