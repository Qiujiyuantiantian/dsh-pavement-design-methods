# 卡 K4 非线性参数标定：两套曲线，标到十二式末端

> 结构层走无侧限逐级加卸载的二次曲线，土基走三轴双曲线，两套不可互换；标定到 5-39 至 5-50 那一串的末端为止，收口式左端按 5-41／5-43 读作切线模量，加荷参数不算卸荷，切线泊松比过 0.49 截断。
> 挂载 verified：f09、f10、p10、ce-A03、ce-A04、ce-A05、ce-A06、ce-A07（8 条）
> 本章只有两张卡能算出数，这是第一张。它的边界不是「算不算得准」，而是「算到哪一步必须住手」。
> 第二张是 K5；两卡不可合并——一张定材料参数，一张算随时间变的响应，输入、输出、几何边界全不同，并了会让人以为标定完就能算黏弹响应。
> 互引：K1、K5

## R 原文论点

第三节的弹性非线性，落地要靠两条曲线；两条各管一类材料，不可互换（ce-A05）。

**结构层：无侧限试件、逐级加卸载、二次曲线（p193）。** 做法是在没有侧限的试件上逐级加、逐级卸，每级量回弹变形，换算成该级的压应力与压应变；点绘成曲线后用二次式回归（母式在 p193 印的是第 4 章的号）。对式求导并按单轴试验的切线定义，得切线模量 5-38；式里两个系数，一个是零应变处的切线斜率（即初始切线模量），另一个与「切线斜率随应变变化的快慢」有关。切线泊松比则按常数取，理由是加载途中它变化不大（p193）。作者在同页把土基另起一段、改用双曲线一套，这个分工本身就是边界。

**土基：常规三轴、双曲线五参数（p193–p195，5-39 至 5-50）。** 先以双曲线拟合偏应力与轴向应变（5-39），再把纵坐标换成「应变除以偏应力」、横坐标仍为应变，双曲线就拉成直线（5-40），直线的截距与斜率就是两个系数。截距的倒数是初始切线模量（5-44、5-45）；斜率的倒数是渐近偏应力（5-46）；渐近值与破坏偏应力之比是破坏比（5-47），于是斜率可由破坏比除以破坏偏应力得到（5-48）；破坏偏应力由黏聚力、内摩擦角与围压算出（5-49）。初始切线模量与大气压的比值，对围压与大气压的比值，在双对数纸上近似成直线（5-50），截距与斜率就是两个幂参数。作者在 p195 把五个参数的取法逐条写了：截距倒数、破坏偏应力乘斜率、直线定幂参数、破坏比各曲线取平均。

**收口两步的自指（p195，5-51 与 5-53）。** 这两式左端都印成初始切线模量，右端却又是它的函数——左端自指。可书内另有依据：5-41 的左端印的就是切线模量，5-43 也把它写成切线模量，所以收口式左端应读作切线模量，不是初始模量（f10）。同一个角色在章内还出现过三个写法：5-35 写 E₁、5-41 写 E_t、5-53 左端写 E_i，指的是一件事（进卡须把三个写法摆在一起，见验证报告第四节第四项）。

**卸荷另有一套（p197）。** 那些常数是从加荷曲线上定出来的，只在荷载继续加大时成立；退荷与再加荷要另取卸荷模量，式 5-65，系数按土类取加荷系数的某个倍数（p197 给了上下限，紧密砂与硬黏土靠下限、软土与松砂靠上限，〔数值待核原图〕，条件：常规三轴、同一围压、应力水平大体一致），指数与加荷时基本相同。

**切线泊松比的截断（p197）。** 应力水平高时会算出大于 0.5 的值，试验里也量得到，作者归因于剪胀；有限元里不小于 0.5 会不合理，到 0.49 就人为取 0.49（〔数值待核原图〕，条件：切线泊松比的高应力段、有限元计算）。改进式 5-64 把切线泊松比在初始值与破坏值之间按应力水平线性内插，破坏值同样取 0.49。

**两条方法学上的否定（p187、p192）。** 割线迭代被作者排除（p187，理由见 K1）；常规三轴那条曲线的割线斜率不具有割线模量的物理意义，侧向曲线同理，能用的是增量式 5-35 与 5-37（p192，ce-A04）。

## I 判据骨架

**两套曲线，一张对照表。**

| 项 | 结构层 | 土基 |
|---|---|---|
| 试件 | 无侧限 | 常规三轴（围压给定） |
| 加载方式 | 逐级加、逐级卸 | 围压恒定、加偏应力 |
| 拟合形状 | 二次曲线 | 双曲线 |
| 直线化坐标 | — | 纵轴换成「应变／偏应力」 |
| 产出 | 三个系数（含初始切线模量） | 五个参数（含两个幂参数） |
| 不许互换 | 拿它去拟合土基 | 拿它去拟合结构层 |

**标定次序（到 5-50 为止，共十二式）。**

1. 5-39 → 5-40：把双曲线拉成直线。
2. 直线的截距与斜率 → 两个系数。
3. 5-44／5-45：截距的倒数是初始切线模量。
4. 5-46：斜率的倒数是渐近偏应力。
5. 5-47：破坏比＝破坏偏应力／渐近偏应力。
6. 5-48：斜率＝破坏比／破坏偏应力。
7. 5-49：破坏偏应力由黏聚力、内摩擦角、围压算出。
8. 5-50：初始切线模量与大气压之比 对 围压与大气压之比 取双对数直线，得两个幂参数。

到此为止：五个参数（两个强度指标、两个幂参数、一个破坏比）齐全。**再往下没有可算的东西。**

**收口两式怎么读。** 5-51 与 5-53 左端自指，不能按印出的符号当恒等式解；按 5-41 与 5-43 的左端，读作切线模量。三处写法（5-35 的 E₁、5-41 的 E_t、5-53 的 E_i）是同一个角色，卡内第一次出现就要并列写出。

**只算加荷、不算卸荷。** 加荷曲线定的常数只对荷载增加成立；卸荷要 5-65 与倍数系数，指数沿用加荷时的值。

**泊松比的截断规则。** 算到 0.5 以上必须截到 0.49（〔数值待核原图〕，条件：高应力水平段、有限元计算）；改进式按应力水平线性内插，破坏值同样 0.49。

**算到哪一步为止（四条，缺一条即越界）。**

① 标定终点是 5-50；5-51 与 5-53 只用来「读回」切线模量，不用来推新参数。
② 收口式左端读作切线模量，读作初始模量会得出自指的方程。
③ 加荷常数不用于卸荷、不用于回弹弯沉。
④ 切线泊松比过 0.49 截断，不截断就不许进有限元。

〔公式待核〕5-38、5-41、5-43、5-45、5-48、5-49、5-50、5-51、5-53、5-65 的式体一律未与原版面核对；本卡只给「哪一步取什么」，不给式面。

## A1 演练

**【合成演练，非书中案例】**

第一段（结构层标定）。来人拿出无侧限试件逐级加卸载的记录，要标出结构层的非线性参数。走二次曲线：点绘、回归、求导，得一条随应变变的切线模量；泊松比在本章按常数取，不要指望它跟着应力跑。

第二段（土基标定）。来人拿出几个围压下的三轴曲线，要五个参数。按次序走：先把双曲线拉直，读截距与斜率，再换成初始切线模量、渐近值、破坏比，最后在双对数纸上取幂参数。走完这一步就住手——再往下没有可算的东西。

第三段（收口式）。来人说左端既是初始模量又出现在右端，问是不是印错了。答：左端按切线模量读，依据是同一节的另一式左端就印作切线模量；不要按印出的字面去解。

第四段（卸荷）。来人要回弹弯沉，想直接用上面标定出的常数。停：那些常数只管加荷段；卸荷要另取一套，指数沿用，系数按土类取倍数。

第五段（泊松比）。来人把高应力段的切线泊松比直接填进有限元。停：必须截断；改进式按应力水平内插。

第六段（割线）。来人想用三轴曲线的首末两点相除当模量。停：那条曲线的割线斜率不具备割线模量的意义，能用的是增量式。

第七段（要响应）。来人说参数既然标好了，就请给一个应力或位移。停：本章第三节只给参数，没有响应链；要响应得出章，或转 K5 看另一条链的几何边界。

## E 执行步骤

**输入契约（要用户提供）**：① 试件有无侧限（定走哪套曲线）；② 是逐级加卸载还是连续加载；③ 每级的应力与回弹变形（或整条曲线）；④ 围压个数与各围压下的破坏偏应力；⑤ 黏聚力与内摩擦角；⑥ 大气压取值；⑦ 是否要卸荷模量；⑧ 是否要切线泊松比、要不要截断；⑨ 后续是否要算响应（要，则本章无出口）。

1. 按有无侧限分流：无侧限 → 二次曲线；三轴 → 双曲线。分错即停。
2. 二次曲线：回归三个系数 → 5-38 → 初始切线模量与随应变变的切线模量。
3. 双曲线：拉直 → 截距与斜率 → 5-45 初始切线模量 → 5-46 渐近值 → 5-47／5-48 破坏比 → 5-49 破坏偏应力 → 5-50 两个幂参数。
4. 到 5-50 停：五个参数交付，不再往下。
5. 若要收口式的切线模量，左端按切线模量读（依据 5-41／5-43），不许按印出的符号自指求解。
6. 若要卸荷模量，另走 5-65，指数沿用加荷时的值，倍数系数按土类取。
7. 若要切线泊松比，先走 5-57／5-58／5-59 一支，再按 0.49 截断；或用 5-64 内插。
8. 若要把它代入有限元算响应：说明本章没有响应链，转 K5 看另一条可算链的几何边界。
9. 输出：参数清单 + 用在哪一段（加荷／卸荷）+ 截断说明 + 不许外推的声明。

**【停判点】**出现下列任一情形必须停下：

- 结构层用双曲线、土基用二次曲线 → 停（两套不可互换）。
- 拿三轴曲线的割线斜率当模量 → 停（无此物理意义）。
- 收口式按印出的符号当恒等式解 → 停（左端自指，须按切线模量读）。
- 用加荷常数算卸荷或回弹弯沉 → 停（另有 5-65）。
- 切线泊松比不截断就直接进有限元 → 停（必须截断）。
- 要求 5-50 之外的参数（温度、频率、加载速率依赖）→ 停（本章无此维）。
- 标定完要求直接给应力或位移 → 停（本章无响应链）。
- 破坏偏应力、黏聚力、内摩擦角三者缺一 → 停（5-49 走不通，破坏比无从定）。
- 只有一条围压曲线就要两个幂参数 → 停（双对数直线至少要两个点）。

## B 边界

**H1 硬边界（不适用）**：两套曲线互换；用割线斜率当模量；把收口式左端读作初始模量；把加荷常数用于卸荷或回弹；让切线泊松比超过 0.49 进有限元；补 5-50 之外的参数；把标定结果当响应结果。

**H2 软边界（降级使用）**：破坏比各曲线不同、书取平均值，所以它是代表值，不是某条曲线的原值；两个幂参数来自双对数纸上的手工直线，换一批点会动；二次曲线的三个系数是回归结果，换试件就换系数；卸荷倍数只有「密实砂与硬黏土靠下限、软土与松砂靠上限」这一句定性分档，中间土类只能内插，且不可当规范值；五个参数只对试验的应力路径成立，外推只到方向。
