## R 原文论点

**四条假定（p175）。** 一是各层均为均质、各向同性、服从虎克定律的弹性材料；二是土基在水平向与向下都视为无限，其上各层厚度有限、水平向无限；三是顶面受轴对称圆形均布竖向荷载，深处与水平远处应力应变归零；四是层间接触面按完全连续处理。四条之下才有那个计算图式（图 5-3，p175）。

**两套界面条件。** 完全连续给四条（5-19，p178）：两侧竖向正应力相等、剪应力相等、径向位移相等、竖向位移相等。完全光滑给三条（5-20，p179）：竖向正应力相等、剪应力两侧同为零、竖向位移相等。界面上的计数随之不同：深处两条去掉之后，连续那套是 4n−2 个待定常数配 4n−2 个方程（p179）；光滑那套是顶面两条加每界面三条，合计 2+3(n−1)，比前者短 n−1 条（此计数为我方复算，非原文）。

**程序的口径（p180–p181）。** 层数上限六，计算点上限二十四；荷载只认单圆竖向均布、作用于顶面；双圆靠单圆解叠加。输入清单逐项看下来，没有任何一个界面参数——这一条比文字更硬：程序根本没有「部分接触」这个开关。

**「界面」与「层间」在章内的分布。** 全章「界面」两次（p183、p185），都是「分界面上」的意思；「层间」四次（p175 两次、p178 两次）。也就是说，第三节讲非线性时一个字没提界面，第五节讲断裂时也没有界面概念（条目 p03）。

**单圆之外的轮迹。** p175 综述里提到非轴对称的水平荷载也能直接数值计算，但那是别人工作的概述，不是本章给的方法；本章自己的解只到轴对称单圆，双圆以外没有解（ce-A08；候选原写 p181，已按更正表改为 180）。

## I 判据骨架

三条前提任何一条不成立，第二节那批敏感性结论就不许搬：

| 前提 | 原文落点 | 成立的样子 | 不成立时 |
|---|---|---|---|
| 材料 | p175 假定一 | 各层均质各向同性、线弹性 | 曲线要进本构 → 转 K4 |
| 几何 | p175 假定二、p180 功能 | 层厚有限、水平无限；层数不超过程序上限 | 层数超限或几何非层状 → 换实现 |
| 荷载 | p175 假定三、p180 功能 | 轴对称单圆竖向均布；双圆只叠加 | 多轮、矩形、水平主导 → 停 |
| 界面 | p178 连续四条件 | 完全连续一套可解 | 光滑只到条件式；滑移、脱空 → 停 |

**界面这一格为什么单列。** 书里把「完全光滑」也写成了条件式，最容易被读成「两条路都能走」。实际差别是方程数：连续那套 4n−2 条，光滑那套 2+3(n−1) 条，短 n−1 条；而程序输入里没有界面参数，两条路里只有一条有实现。

**四条与三前提的关系。** 四条是书的原文清单，三前提是本文的收口方式（材料／几何／荷载），界面单列。对不上任何一条，结论强度一律降到「方向」，不给数。

〔公式待核〕5-19、5-20 两套条件只按「几条、哪几个量」引用，式体未与原版面核对；4n−2 与 3n−1 是计数，不是算出的物理量。

## A1 演练

**【合成演练，非书中案例】**

第一段（层数）。来人报了一个层数超过程序上限的体系，问能不能照第二节的表格取数。停：上限是这一版程序的功能边界，不是物理边界；超限就换实现，表格里的敏感性结论不跟着走。

第二段（界面）。来人要做层间滑移，问是不是把连续条件换成光滑条件就行。停：光滑那套在本章只停在条件式，方程数比连续那套短，程序也没有这个开关；要滑移只能出章。

第三段（轮迹）。来人给的是双轮组、轮迹近似矩形。先判：双圆可以按单圆解叠加，矩形轮迹在本章没有解；只能退到「双圆叠加＋方向判断」。

第四段（荷载方向）。来人的工况以水平力为主。停：本章的解是轴对称竖向均布，水平力只在综述里被提到，不在方法内。

第五段（假定对不上）。来人说某层材料明显非线性，但仍要按第二节取数。可以取，但结论只到方向；曲线进了本构就是第三节的事（K4）。

第六段（拿结论）。来人要一份「层间粘结差一点会差多少」的估计。停：本章没有任何界面参数，也没有滑移工况的算例，差多少这个量在本章不存在。

## E 执行步骤

**输入契约（要用户提供）**：① 层数与各层厚度；② 各层模量与泊松比；③ 荷载半径与接触压强；④ 计算点的径向与竖向坐标；⑤ 轮迹形式（单圆／双圆／其它）；⑥ 层间状态（连续／光滑／滑移／脱空）；⑦ 是否接受结论降级为方向。

1. 数层数，对程序上限；超限即判「本章只有方向」。
2. 问层间状态：连续 → 可往下；光滑 → 只到条件式；滑移或脱空 → 停。
3. 问轮迹：单圆 → 可往下；双圆 → 只许叠加；其它 → 停。
4. 问荷载方向：竖向为主 → 可往下；水平为主 → 停。
5. 逐条对四条假定，把对不上的那一条记下来，作为结论降级的依据。
6. 输出：可用（连续＋单圆＋竖向＋假定齐）／降级为方向／不可用，并写明是哪一条前提破的。

**【停判点】**出现下列任一情形必须停下：

- 层间状态是滑移或脱空 → 停（本章无此解，程序无此输入）。
- 轮迹不是单圆也不是双圆 → 停（无解）。
- 荷载以水平向为主 → 停（方法内不含）。
- 层数超过程序上限却要求照表格取数 → 停（结论不可搬）。
- 材料明显非线性却要求按线弹性给数 → 停（降级为方向，转 K4）。
- 要求给出界面参数（刚度、摩阻、脱空尺寸）→ 停（输入清单里没有）。
- 拿「完全光滑」当第二条可算的路 → 停（只到条件式，且短 n−1 条方程）。
- 要求在层间设接触单元再回来对本章的数 → 停（本章没有接触单元这条路）。

## B 边界

**H1 硬边界（不适用）**：把光滑界面当可算路径；给界面刚度、摩阻或脱空尺寸；把矩形轮迹或多轮组塞进这套解；把第二节的敏感性结论搬到滑移、脱空、多轮工况上；把「完全连续」当实测结果（它是假定）；用超过程序上限的层数取数。

**H2 软边界（降级使用）**：四条假定只能逐条对、不能补误差界——书没给偏离假定后的后果；词频那组数字（两次、四次）是计数，随文件版本变；p175 那条「非轴对称水平荷载可直接数值计算」是综述别人的工作，不能当本章能力；层数上限与点数上限是这一版程序的口径，换程序要重核。
