# C9 E／K／CBR：一条关系，不是三条式子

> 本章唯一"三条式子互相精确自洽"的地方，也正因如此最容易被当成三条独立式各用一次。它同时是全章"单位制先定"这条纪律的唯一硬样本。
> 挂载 verified：f12、ce-A05、p10、ce-A04（4 条）
> 互引：C8（FAA 侧的模量表）、C10（9-63 里的 K 另一种单位）、C4（输入口径）、C1（归族）

## R 原文论点

三条式面：式 9-47（p456）把路基模量写成反应模量的幂函数；式 9-48（p456）把反应模量写成承载比的幂函数；正文两处（p446、p451）给模量与承载比的直线关系，一处注明单位为兆帕、一处注明单位为磅每平方英寸。

p451 写得很直白：换算时用 1500 乘承载比（此时模量单位是磅每平方英寸），或用 10 乘承载比（此时模量单位是兆帕）。这两条不是两个关系，是同一条关系的两种单位写法。

f12 的要点在于 9-47 与 9-48 不是两套独立试验的产物，而是为复现那条直线关系反拟合出来的一对。用本章自带常数复算：承载比取 3、5、10、20、33，先由 9-48 得反应模量，再由 9-47 得模量，五点与 1500 乘承载比的偏差都在万分之二以内〔复算，非原文〕。三式一荣俱荣，所以不能当三条用，也不能拿其中两条去"互相校核"第三条。

ce-A05 抓的是单位制：两式实为英制（反应模量用磅每立方英寸、模量用磅每平方英寸），而它们紧跟在一张以兆帕为单位的参数表（表 9-40，p449）之后。按兆帕直代反应模量八十，得出来的模量在五千五百兆帕上下〔复算：5,595.6，验证报告记 5,594〕，是表 9-40 道基上限的三百五十兆帕的十六倍。这个数看起来"像个模量"，所以最难发现。

p10 记的是承载比在本章的多种身份，用前必须先判是哪一种：表 9-13（p420）与表 9-27（p435）里是道床填料的验收值；p422 给基层材料的设计要求（上基层不低于一百、下基层不低于九十、砾石下基层不低于八十）；p446 是模量换算的输入；p476 是通报的地基强度四档（十五、十、六、三）；p462 起是厚度式里的两层（计算深度处与路基顶面）。同一个名字，五种身份，一种用错，一条链就废。

ce-A04 补的是厚度式的适用域：式 9-55 前面那个括号，承载比取一千时得 83.7，除一百才是 0.837〔复算，非原文〕——括号的写法与实际用法差一个百分数口径。适用域在书里有三种说法，分指三件事：式内要求小于十到十二（p462）、正文再说一次小于十二（p462）、设计曲线在承载比到百分之五十处终止（p463）。三件事不是同一个界。

## I 判据骨架

| 对象 | 位置 | 判读 |
|---|---|---|
| 幂式对 | 9-47、9-48（p456） | 反拟合对，与 1500CBR 自洽 |
| 直线关系 | p446、p451 | 兆帕配 10，磅每平方英寸配 1500 |
| 单位制 | p456 与表 9-40（p449） | 式子英制、表是兆帕，先换再代 |
| 身份 | p420、p422、p435、p446、p462、p476 | 五种身份，先判再用 |
| 适用域 | p462、p463 | 式内域、正文域、曲线终止域三件事 |

三条：

① **先定单位制**：英制式配英制量，兆帕式配兆帕量；直代得到的数会"看起来合理"；
② **三条是一组**：9-47、9-48 与那条直线关系互为反拟合，不许拆成三套各用；
③ **先判身份**：承载比在这一章是五种东西，取错身份，量级与量纲都可能错。

〔公式待核〕9-47、9-48 的系数与指数（20.15、1.284、28.6926、0.7788）回原页核；9-54 与 9-55 的括号与常数（0.57、三点一四、23.1、14.4）同。

9-47 与 9-48 的系数、以及直代得到的五千多兆帕均〔数值待核原图〕并附〔复算，非原文〕，条件为反应模量取八十、且单位制未先判。

## A1 演练

**【合成演练，非书中案例】**

第一段（定单位）。来人报路基反应模量，问对应模量。先问他这个数是英制还是兆帕。答不出，停，不许两套都算一遍再看哪个"像"。

第二段（认身份）。再问这个承载比是哪一种：填料验收值、基层材料要求、换算输入、通报道基档、厚度式内值。五种身份取数不同。

第三段（代式）。按英制代 9-47 与 9-48，或用兆帕那条直线；两套不得混代。

第四段（校核）。若有人拿 9-47 的结果去"校核" 9-48，说明他把反拟合对当成了两次独立试验。判误读，停。

第五段（适用域）。承载比超出式内那个域，就不许再代厚度式，改读曲线终止那一句。

## E 执行步骤

**输入契约（要用户提供）**：①承载比或反应模量或模量（至少一个）；②单位制（英制／兆帕）；③承载比的身份；④计算深度（式内还是路基顶面）；⑤是否要进厚度式；⑥出口（换算值／判能不能代／校核一致性）。

1. 问单位制，判不出即停。
2. 问承载比身份（五种之一），定取哪一个数。
3. 按同一单位制代 9-47 与 9-48，或用直线关系。
4. 做一致性检查：三点互推的偏差应在一处小数百分比以内；偏差大说明单位或身份错。
5. 判适用域：超出式内域即停，改走曲线终止那一句。
6. 出口：模量交 C8（取表 9-40）或 C10（9-63 里的反应模量）。

**【停判点】**出现下列任一情形必须停下，不得估算补齐：

- 单位制不判就代 → 停（兆帕直代得五千多，是道基上限的十六倍）。
- 把 9-47 与 9-48 当两套独立试验、要"互相验证"→ 停（反拟合对）。
- 承载比身份不判 → 停（五种身份取数不同）。
- 承载比超出式内域还代 9-55 → 停（三种域不是同一个界）。
- 拿 9-55 的括号直接当乘数（不除一百）→ 停（差两个数量级）。
- 要求"哪一条更权威"→ 停（三条是同一个关系，没有权威之分）。

## B 边界

**H1 硬边界（不适用）**：不把直线关系外推到刚性板的地基参数；不把通报的地基四档当设计输入；不给英制与兆帕之间的额外换算系数（书里只有那两条）；不把 9-47 用到混凝土板的板底应力式里（那里的反应模量是另一种单位写法，见 C10）。

**H2 软边界（降级使用）**：9-47 与 9-48 的"英制"是从系数与数值反推的〔推断〕，书里没写单位；复算偏差在万分之二以内，只能说明三式自洽，不能说明它们对任何土都准；承载比的五种身份里，p422 的三个数（一百、九十、八十）是材料要求，不是设计强度。
