## R 原文论点

这一章不是"算不出的章"，是"断点密集的章"。作者把适用条件写得比公式可靠（十二条边界条件全是他自己交代的），而公式一侧的损伤是系统性的、不是随手抄错：两处特征长度互为倒数、六块矩阵没有一块成形、翘曲位置值差四倍。再加上原件缺失——0 张表、0 个算例、0 个 E／K／板厚取值、图号与图题对不上——读者拿到的其实是一份"哪里不能走"的地图。

所以这张卡不讲算式，只讲四类"见即停"。

## I 判据骨架

四类判据面：

① **含 l 的式**。p219 的 l 把 K 写在分子，p250 的 l 把 K 写在分母，两者互为倒数。由 p250 的 6-166 与 6-167 只能推出 l 的四次方等于 D 除 K，故 p250 为准、p219 为误。凡要代 l 的，停。
② **p223 那一处的 l**。它根号里的分子与分母同写 (1−μ₀²)，约掉之后 l 与 μ₀ 无关；而 6-40、6-43、6-46 到 6-48 仍逐个带 μ₀。同一页的 6-43 分母是"一加 l 的负三次方乘 ξ 的三次方"，p224 的 6-46 到 6-48 是"l 的负三次方加 ξ 的三次方"，两处差一个因子。凡要代这一支的，停。
③ **六块矩阵**。p231 的地基刚度阵、p232 的简化支柱阵、p233 的 6-86、p236 的 6-101、p238 的 6-103、p240 的 [K]′——没有一块是完整方阵：有的上三角之后又降级成正文散字，有的行数够而列声明不匹配，有的乘的向量元素个数不对，有的同一位置先印一个系数后印另一个。凡要拿它求逆、编程序、做网格收敛的，停。
④ **要按位置取翘曲应力**。p248 的 6-157 与它同组另两式差四倍；p252 的 6-178 把两个方向交叉配对、6-179 一个号用了两次、6-179 与 6-180 在同一点给出一正一负；6-174 与 6-175 里的 λ 在被用之后才定义。凡要位置值的，停。

另有两处局部断点：当量半径的第二支条件自指（6-25，右边界仍写同一个 R），b 的定义域只剩一半；板底脱空在本章只有名词、没有式子（5 次，全在 p213／214／224／225）。

〔公式待核〕本卡不列任何算式——它只判"这一条能不能代"，不作代。

## A1 演练

**【合成演练，非书中案例】**

第一段（要代 l）。来人要拿第二节三荷位的式子算一个应力。三支六个式子都含 l，而 l 在两处互为倒数。判：停；并同时给出两处的页码——只给一处，会被当成笔误而不是对立。

第二段（要编程序）。来人要按第六节的矩阵写一个求解器。六块矩阵没有一块成形，单元形函数与应力矩阵还被推给参考文献。判：停。

第三段（要位置值）。来人要板中某一点的翘曲应力。中部那一支与同组另两式对不上，位置式又交叉配对。判：停，只给基准值。

第四段（要读图）。来人问某个荷位的方位与正负号。图号比图题多，图题又比真正的图像占位多。判：凡须读图才能定的，只能定性，不能当数值来源。

第五段（脱空）。工况含板底脱空，来人问能不能给一个折减。全章"脱空"只出现在名词层，零条式子。判：停，不给折减系数。

## E 执行步骤

**输入契约（要用户提供）**：①要代的对象（式号 + 印刷页）；②要不要出数；③要不要按位置取值；④要不要用矩阵；⑤要不要读图；⑥工况里有没有脱空或支承不均。

1. 先看对象属于哪一类：含 l／含矩阵／位置值／纯符号。
2. 含 l 的，核三处：p219（K 在分子）、p250（K 在分母）、p223（根号内分子与分母同写 (1−μ₀²)）。任一处被点到就停，并且两处对立的页码要一起给。
3. 含矩阵的，核行数与乘的向量元素个数是否一致；不一致即停。
4. 位置值的，核 6-157 与同组另两式、核 6-178 与 6-179、核 6-179 与 6-180；不一致即停。
5. 读图的，核图号与图题是否对得上；对不上只能定性。
6. 输出：停或不停 + 停在哪一条 + 页码。

**【停判点】**（本卡的全部内容，逐条具体）

- **p219 的 l**（K 与分数相乘，写在分子）→ 停。
- **p223 的 l**（根号内分子与分母同写 (1−μ₀²)，约掉后与 μ₀ 无关，而 6-40、6-43、6-46 到 6-48 仍逐个带 μ₀；6-43 与 6-46 到 6-48 的分母还差一个因子）→ 停。
- **p250 的 l 是对的，但不许用**：正确形式（K 在分母）确实在书里，所以停判的理由不是"信息缺失"，而是"不许替原书改式 ＋ 全章 0 个参数取值"。
- **六块矩阵无一块完整**（p231、p232、p233 的 6-86、p236 的 6-101、p238 的 6-103、p240 的 [K]′）→ 停。
- **图**：图号 24 个（6-1 到 6-24 连续）、图题 13 个、图像占位 4 个（p221 两张、p244 两张）；凡须读图定正负号与荷位方位的，只能定性。
- **0 张表、0 个算例、0 个 E／K／板厚取值** → 任何要出数的，停。
- **脱空**：5 次全在 p213／214／224／225 的名词层，0 条式子 → 工况含脱空的，停，不给折减。
- **当量半径第二支自指**（6-25 第二支的右边界仍写同一个 R）→ 停，b 的定义域只剩一半。
- **思考题**：第七题问的那类图在正文出现 0 次；第十三题问的第二个公式名在正文出现 0 次 → 这两题在本章范围内无内容，停。
