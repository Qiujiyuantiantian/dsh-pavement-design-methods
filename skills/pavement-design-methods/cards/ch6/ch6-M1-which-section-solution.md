# M1 先选节：四选一，选完先过失效前提

> 拿到一个混凝土板的问题，先判它落在本章哪一节：第二节的三荷位闭式解、第三节的弹性半空间、第四与第五节的有限元、第六节的温度。选定之后第一件事不是代值，而是拿该节自己写下的失效前提过一遍；前提一破就停在节门口。

## R 原文论点

本章把"板与地基"这件事铺成五节，却**没有一张表告诉读者按什么条件挑**。第一节是早期的角隅悬臂反解（p213–214）；第二节换成温克勒地基上的三荷位闭式解（p214 起）；第三节再换成弹性半空间（p221 起）；第四、五节把同一块板交给有限元（p224、p234）；第六节单独处理温度（p241）。每一节都把自己的前提写了下来，却从不在节与节之间比较——挑选这件事，原文只给了材料，没给判据。

还有一层更要紧：**前提比公式可靠**。本章过三关的十七条条目里有十二条是作者自陈的适用条件；同一批公式抽样下去，过半数代进去就错。所以这张卡落在"选"上，不落在"算"上。

全章最贵的一句自评在 p221：用温克勒描述板下的支承，作者自己承认这一手有时过简，也把地基的承载能力估低；同页还转述威氏后期把这个假定说成"便于应用"的权宜之计。而 K 与 E₀、μ₀ 之间**没有任何一条桥接式**——于是"何时该换"有据，"换成多少"无据。

## I 判据骨架

四选一，每一支连同它自己的失效前提一起带走。表里只放"什么时候不能用"，不放算式。

| 支 | 节／页 | 该支自己要的前提 | 前提破了的信号 | 破了之后 |
|---|---|---|---|---|
| 三荷位闭式解（温克勒） | 第二节，p214 起 | 板下反力与挠度成正比（6-20）；薄板、小挠度；轮印半径与板厚相差不大 | 基层成层或刚度大、轴载重；板中实测偏低（p220 把原因归给反力向加载点集中）；半径远小于板厚 | 停。全章没有 K 到 E₀／μ₀ 的桥，换不了 |
| 弹性半空间 | 第三节，p221 起 | 三条：变形中板与地基始终接触、接触面不传水平剪力、地基均质各向同性（p222） | 板底脱空、支承不均；地基成层 | 停。作者自己说这两类问题解析解办不到（p225），只能转有限元 |
| 有限元 | 第四、五节，p224 起 | 矩形薄板单元、位移法、结点按刚性连接；形函数矩阵与应力矩阵推给参考文献（p230） | 网格粗、单元非矩形；挠度很不均匀或边界受约束；多层地基；五块板体系的四条前提缺一条 | 停或降级。收敛没有误差界（p229）；简化支柱法只在挠度均匀时可信（p232） |
| 温度 | 第六节，p241 起 | 全厚度同温只对年周期；梯度段的推导前提是温度沿厚度线性、板与地基不脱开（p249） | 日周期、骤降温；对称分布；边界被钳死；板可能脱开 | 停。翘曲式只在一道窄缝里成立（见 M4） |

三条硬规则：

① **先选节，再代值**。节没定就代值，等于把两套地基口径混进一条链。
② **一节一前提**。前提不是"注意事项"，是开关：破一条即停，不许"先算完再讨论"。
③ **不补式**。本章的坏处在特征长度 l（见 M6）；拿记忆里的标准式去补，等于替作者改错，也把"这页不能用"这个信息抹掉。

〔公式待核〕本卡只引节与前提，不列算式；表里的 6-20 只作定位。

**"整节失效"这句话必须收窄**，这是本章最容易被写宽的一处。第二、三节按阶段 1 的口径算 60 个式块，其中 6-5 到 6-20（薄板几何、物理、弯矩、平衡、板方程）与 6-32 到 6-42（半空间的表面位移与亨格尔变换）**都不含 l**；它们不可算的原因是另一个：全章没有参数取值。所以不能说"第二、三节整体作废"。恰恰相反，6-9 → 6-10 → 6-11 → 6-13 → 6-14 这一串每步只依赖前一步，是本章唯一能当基准用的骨架：下游任何一条式子与它不符，先疑下游。写宽一句，这条基准会跟着被废掉。

## A1 演练

**【合成演练，非书中案例】**

第一段（选节）。来人给一个基层成层、轴载偏重的工况，问能不能用第二节那组三荷位式子。查该支的前提：板下反力与挠度成正比这一条，作者自己在 p221 说过于简单、低估承载能力；再问 K 与 E₀、μ₀ 怎么换，全章无桥。判：停在该节门口，不许把 K 折成 E₀ 再套半空间。

第二段（脱空）。工况里写明板底局部脱空。半空间那支的第一条前提是始终接触（p222），直接破；作者又说这类问题解析解办不到、要靠有限元（p225）。转有限元——而形函数矩阵与应力矩阵被推给参考文献（p230），六块矩阵又没有一块成形（见 M6）。判：这条链在本章走不到底，只能给方向。

第三段（补式）。来人掏出一条"通用"的板角应力式，说要补上 6-21 那一族的缺。不许。本章那几式的病在 l；补标准式等于替作者改错，也把"这页不能用"抹掉。判：停，只记"该式不可代"。

第四段（粗网格）。有人拿一套粗网格算出的挠度当收敛解。p229 明说公共边上另一个转角只被两端结点值部分限制，两个单元在该边上本就有差异；收敛靠单元逐步取小，全章没有误差界。判：降级为参考，不进判据。

第五段（半径）。轮印半径远小于板厚，仍按原式算。p219 说这时薄板假定不合用，要改当量半径；而改半径的两支里，第二支的条件自指（门槛两侧写的是同一个 R），定义域只剩一半。判：落在后半段就停。

## E 执行步骤

**输入契约（要用户提供）**：①地基描述（单层／成层、有无脱空或支承不均）；②荷载口径（单轮／单侧／整车、轮印尺寸、是否重载）；③板的描述（厚度是否已知、是否分块、有无接缝）；④温度工况（年周期均匀温／日周期梯度／两者都要）；⑤出口（只要判"能不能算"／要应力或位移／要板厚）；⑥若走有限元，单元形状与网格密度。

1. 按地基描述定支：单层、无脱空、反力可与挠度挂钩 → 第二节；成层或要连续介质 → 第三节；脱空、支承不均、多板、多层 → 第四／五节；温度 → 第六节。
2. 把该支的前提逐条抄成清单（表里那一列），一条一条打勾，不许合并、不许"大致满足"。
3. 勾不上的，回第 1 步换支；换不了就停，并在输出里写明破的是哪一条、在哪一页。
4. 出口含"板厚"的，不在本卡求，转 M2；含"接缝传荷"的转 M3；含"温度"的转 M4。
5. 走有限元的，先查三件：单元是否非矩形、网格是否粗、板下地基是否多层。任一条命中，解降级为参考。
6. 输出：所选节 + 打勾后的前提清单 + 能否出数（多数工况下答案是"不能"，理由见 M6）。

**【停判点】**出现下列任一情形必须停下，不得估算补齐：

- 工况含板底脱空或支承不均 → 停（全章"脱空"5 次全在名词层、0 条式子，见 M6）。
- 手上有 K、要折成 E₀ 或 μ₀ 再算 → 停（全章无桥接式，p221）。
- 只有一条记忆里的标准式，没有版本、没有页码 → 停（不许补式）。
- 落在当量半径的后半段（6-25 第二支条件自指）→ 停。
- 网格粗却要求"当收敛解用" → 停（p229 无误差界）。
- 五块板体系里出现边板同受荷、板长不等、接缝传弯任一条 → 停（压缩矩阵法的前提断，p238）。
- 多层地基要取荷载中心处的柔度 → 停（p237 自陈回归在中心附近偏差大，中心值须改层状解，而该式未给）。

**确实是 E 与 K 的换算式**，但幂次落 2/3 与 4/3、互不逆，**只是两条同名式子、不是同一关系**。

## B 边界

**H1 硬边界（不适用）**：算板内应力与位移（三荷位那族式全含坏 l，见 M6）；给地基参数取值（全章 0 个 K／E／板厚）；把"改换半空间""改换有限元""中心值改层状解"写成算式（原文只给方向）；按位置取温度翘曲应力（M4 的窄缝）；板厚设计（M2）。

**H2 软边界（降级使用）**：四选一这张表是自建的——原文按节铺开，没有这张对照。表里"破了之后"那一列只有"停"与"转有限元"两种，没有第三种，因为作者自己也没给替代算式。f02 那条骨架能当基准，但它只到"弯矩—应力"这一层，不含地基、不含温度。

**与书 2 第 5 章的边界（①同底座不同层）**：两边共用薄板假定、弯曲刚度与特征长度这套底座，但一边解静力（轮载与温度）、一边解动力（移动荷载、惯性、多地基取舍），只能互指为"同一底座的静力侧与动力侧"，不能当成同一内容的两个版本——那样读者会以为两处能对算。
