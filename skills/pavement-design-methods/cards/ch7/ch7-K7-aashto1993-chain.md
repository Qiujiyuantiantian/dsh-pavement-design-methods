# K7 AASHTO 1993 闭环

> 全章唯一能从交通量一路解到分层厚度的链；它只属 AASHTO 1993，单位制是 psi 与英寸，不能套到我国法。
> 挂载 verified：f11、p14、c09、c10；背景 reference：p13（只作停判依据，不进执行步骤）
> p13 作 background：反例方向须改写后才能当停判依据，本卡只在 B 段引用其结论。
> 互引：K3、K1、K11

## R 原文论点

设计方程把累计当量轴次、可靠度、交通与性能的综合偏差、服务性指数差、路基回弹模量五样输入收在一个对数式里，解出结构数（式 7-55，p286）。结构数不是厚度，它是各层「层系数 × 厚度 × 排水系数」的和；三个层系数各有一条对数式，分别对应沥青层、粒料基层、粒料底基层（式 7-56 至 7-58，p286–288）。排水系数由排水等级与饱和度差查两张表（p289）。拿到结构数以后按四条分层式逐层分配厚度：先假定第一层，算出所需厚度，再回算实际结构数，逐层往下（p291）。同时有最小厚度表兜底，六档累计轴次各给沥青层与粒料层下限（p291）。算例给了五个输入并得到结构数，但止于结构数，没有继续定厚（p290）。书中对交通与性能的综合偏差只给了名称与含义，算例里的取值是该例自设（p286、p290）。

## I 判据骨架

链路：五输入 → 结构数 → 三个层系数 → 排水系数 → 逐层厚度 → 最小厚度校核。

| 步 | 式子 / 表 | 要点 |
|---|---|---|
| 1 解结构数 | 7-55〔公式待核〕 | 对数式，五个输入缺一不可 |
| 2 层系数 | 7-56、7-57、7-58〔公式待核〕 | 模量以 psi 进式，出来的系数无量纲 |
| 3 排水系数 | 表 7-27、7-28〔数值待核原图；条件：排水等级 + 饱和度差，仅粒料层〕 | 只对粒料层用；沥青层不乘 |
| 4 逐层分配 | 四条分层式〔公式待核〕 | 先假定、再回算、逐层往下 |
| 5 最小厚度 | 表 7-30〔数值待核原图；条件：累计当量轴次档，仅沥青层与粒料层〕 | 只覆盖沥青层与粒料层 |

四个必查的坑：

1. 单位制。模量要 psi、厚度要英寸；把 MPa 与厘米直接代进去，结构数会整体偏大或偏小，且看不出来。
2. 层系数的试验口径。沥青层的系数只对一种室内回弹模量标定过，换动态模量系数会跳档（转 K3）。
3. 排水系数只乘粒料层；乘到沥青层上等于重复折减。
4. 最小厚度表没有稳定类基层的下限——稳定类基层没有对应兜底，这一点书里没补。

算例可复算的部分（不列数值）：五输入代入式 7-55 解出结构数，与书上结果一致；算例止于结构数，未继续分层。

## A1 演练

**【合成演练，非书中案例】**

**第一段（走通）。** 手上有累计当量轴次、可靠度、交通与性能综合偏差、服务性指数差、路基回弹模量，且都以英制给全。按链路走：解结构数、算三个层系数、查排水系数、逐层分配、最小厚度校核。五步都过，即可给出分层厚度。

**第二段（停在单位制）。** 模量给的是兆帕、厚度给的是厘米。停在第一步之前：先把两者换成 psi 与英寸，再进式；不换就解，结构数没有物理意义。

**第三段（停在综合偏差）。** 可靠度给了，交通与性能综合偏差没给，只说「按经验」。停在解方程这一步：该输入书中只有名称与含义，算例里的取值是该例自设，不能当通用值。

**第四段（停在最小厚度）。** 结构里有一层水稳基层，逐层分配算完了，想用最小厚度表兜底。停在这一步：该表只覆盖沥青层与粒料层，稳定类基层没有下限；缺的不是数值，是这一层的兜底规则。

## E 执行步骤

**输入契约**：①累计当量单轴次数；②可靠度与综合偏差（后者须注明来源）；③初终服务性指数；④路基回弹模量（psi）；⑤各层材料与拟用厚度（英寸）；⑥排水等级与饱和度差；⑦基层类型（判断有无最小厚度可用）。

1. 单位制先行：全部换成 psi 与英寸，写在表头。
2. 解结构数，保留中间量（对数项分开写，便于回查）。
3. 算三个层系数，逐个核对试验口径。
4. 查排水系数，只对粒料层乘。
5. 逐层分配：假定第一层 → 回算实际结构数 → 下一层。
6. 用最小厚度表校核，无对应行的层单独标注「无兜底」。
7. 输出去向：厚度给施工图；口径疑点转 K3；与我国法对比时明确「不可折算」。

**【停判点】**出现下列任一情形必须停下：

- 模量或厚度不是 psi 与英寸 → 停，先换算。
- 综合偏差没有来源、只有一个数 → 停。
- 层系数所用模量的试验方法不明 → 停。
- 结构里有稳定类基层却指望最小厚度表兜底 → 停（该表无此行）。
- 有人要求把这套厚度直接当我国规范的厚度 → 停（两法不可折算）。

## 停判点补充：服务性指数差也要停

本卡【停判点】原只列了「交通与性能综合偏差只有一个数、没有来源」。**服务性指数差 ΔPSI 同样没有取值规则**
（`ch7-K1-method-routing.md` 已把这两处并列）——两处都必须停，不能只停一处。

## B 边界

**H1 硬边界（不适用）**：我国各代规范的厚度确定（本章不给反解步骤）；水泥混凝土路面；需要力学响应计算的场合（本法是经验法，不解应力应变）。

**H2 软边界（降级使用）**：反例档（p13）只作背景，其方向须改写后才能用；服务性指数体系本身几乎只反映平整度（转 K11），所以本法算出的厚度只对「以平整度衰变为主要损坏」的情形有把握；一图未得，凡需查图定结构数的场合只能改用解方程。
