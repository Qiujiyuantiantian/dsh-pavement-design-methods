## R 原文论点

本章五节各有一套模量、轴载、弯沉与可靠度，作者自己三次点明口径不通：层系数只认一种室内回弹模量，换成动态模量后系数从零点四二跳到零点六以上〔数值待核原图；条件：二十度、原式为劈裂回弹模量口径〕（p286）；CBR 法用均质体、泊松比取零点五，结果系统性偏保守（p304）；沥青层模量在 2006 与 1997 两代还分静动两套（p271）。轴载换算的幂次跟着被控指标走：以弯沉或以沥青层底拉应力为指标时用四点三五次幂，以稳定层底拉应力为指标时用八次幂，两式的两个系数各取一套（p267）；再早一代还出现过四次与五次幂、以及把第一个系数定义成轮组系数的写法（p265）。可靠度在我国法里同时进寿命式与验收式，而章末又把同一个 β 当标准差乘子用，与等级表里的 β 不同源（p317、p335）。AASHTO 的可靠度要两个输入，书里只交代了一个的取法（p286）。1997 版拿一套模量同时管弯沉与拉应力，2006 版改成按计算层上下分取高低值，作者明说这是在纠前一代把保证率方向搞反（p270）。

## I 判据骨架

四类口径，各自成表；跨表搬运即判错。

| 类 | 本法口径（逐条带页） | 不可换给谁 |
|---|---|---|
| 模量 | 我国 17 版：二十度动态压缩模量，沥青稳定碎石按五赫兹；层系数只认劈裂回弹模量（p272、p286） | AASHTO 的层系数；AI 的动模量与 Shell 的劲度 |
| 轴载 | 我国按指标分派幂次：弯沉与沥青层底四点三五、稳定层底八（p267）；更早一代四与五（p264） | 任何按单一指数换算的当量次数 |
| 弯沉 | 设计弯沉（1997 起）与验收弯沉是两个物，都以百分之一毫米计〔数值待核原图；单位制：0.01 mm〕但基准不同（p267、p335） | 拿设计值当验收值 |
| 可靠度 | 我国：目标可靠指标按等级表取（p317）；AASHTO：Z_R 与 S₀ 两个输入（p286） | 把 β 当标准差乘子，或把 S₀ 当通用常数 |

## A1 演练

**【合成演练，非书中案例】**

**第一段（模量搬错）。** 来人把十七版的动态模量填进 AASHTO 的层系数式，得到一串看起来很漂亮的系数。停在这一步：该式只对一种室内劈裂回弹模量标定过，换了试验方法，系数就不是原系数；缺的不是数值，是同一试验口径。

**第二段（指数搬错）。** 有人拿稳定层那一套八次幂去换算弯沉设计用的轴次，理由是两个式子长得一样。停在指数这一步：指数是与被控指标绑定的，换了指标，同一个车队算出的当量次数就不同；缺的是该指标自己的换算式。

**第三段（同一个 C₁）。** 有人从更早一代抄来轮组系数，代进后一代的轴数系数位置，单轮组与四轮组整列错位。停在「同名不同义」这一步：两处 C₁ 一个是轮组、一个是轴数；缺的是把两式各自的系数表并排看一遍。

**第四段（可靠度）。** 有人把等级表里的 β 直接搬进验收弯沉式当标准差乘子用，数值算得出来，含义已经换了。停在这一步：同一个字母在两处是两种用法；缺的是说明「此处 β 是乘子还是指标」的那一句话。

## E 执行步骤

**输入契约**：①方法名与版本（哪一代、哪一国）；②每个量的试验方法或来源（试验类型、温度、频率、单位制、荷载口径）；③该量要去的目标式。

1. 给每个量贴三张标签：方法名、试验口径、单位制。
2. 查四类口径表，确认这个量在原方法里的身份。
3. 查十六组清单，看目标方法里是否有同名项；有则判「不可互换」。
4. 若确需跨法，改为重算：用目标方法自己的换算式与参数从头算一遍。
5. 把不能互算的两列并排保留，别折成一个系数。
6. 输出一张「量—口径—可否搬运—理由」表，交给下游卡片。

**【停判点】**出现下列任一情形必须停下：

- 只给数值、不给试验方法与温度频率 → 停（口径未定，数值无意义）。
- 目标式要求劈裂回弹模量，手上只有动态模量 → 停。
- 两式同名系数而身份不同（如 C₁）→ 停，先分清再代。
- 只有一套模量却要同时用于弯沉与拉应力，且属 1997 那一代 → 停（该代保证率方向已被作者自陈搞反）。

> **代际标签**：本卡记的 4.35（弯沉／沥青层底）与 8（稳定层底）是 **1997 口径**（p267）。
> 2017 版改用另一组（拉应变与永久变形 4、路基压应变 5、稳定层拉应力 13，见 `ch2-C2-exponent-caliber.md`）。
> **两组不可对齐、不可互推**；引用时必须连同代际一起写。

## B 边界

**H1 硬边界（不适用）**：把本章口径当成现行规范条文来引用（本章只记录该书所写的各代做法）；需要把 psi 与 MPa、inch 与 cm 做工程换算之外的力学等效；要求给出跨法换算系数的题目——本章明确不给换算桥。

**H2 软边界（降级使用）**：十六组表只写性质不写取值，取值必须回原书页并标〔数值待核原图〕；p265 那一代与 p267 那两代不同版本，混引即错代；p15 / p16 / p17 三条局部规则只作边界注，不能当独立判据。
