# K2 指标与标准指派

> 先认出基层与底基层这两个身份，再据此查得该结构要验算的指标串；换一种组合就必须换一串指标，指标个数也会变。
> 挂载 verified：f18、p01、p02、p03
> 并入条：p09
> p09 是一句话的排除项（沥青碎石类不验算层底拉应力），按验证小结并入本卡，不单独成条。
> 互引：K3、K4、K5

## R 原文论点

指派表只有两维：基层类型与底基层类型，共七种组合，公路等级这一维不在表里（p328）。其中，拿无机结合料稳定材料做基层、粒料做底基层的那一行，与上下两层都拿无机结合料稳定材料做的那一行，给出同一串指标；拿沥青结合料做基层、粒料做底基层的那一行，是三项齐全的一行；把底基层换成无机结合料稳定材料，串里就改取稳定层底的拉应力，并把路基压应变撤掉；两行粒料基层各有自己的串；拿水泥混凝土做基层的那一行，只剩永久变形一项（p328–p329）。另一张表按结构类型与沥青层厚度给出主要损坏类型，厚度分界处车辙与疲劳的主次关系对调（p328）。注 1 给季冻区追加两项，注 2 给「沥青层与稳定层之间夹粒料层」追加沥青层疲劳寿命的验算（p329）。此外，沥青碎石类被参数表的一条注排除在层底拉应力验算之外，书中没有交代理由（p270）。

## I 判据骨架

两步定位，一步补规则。

第一步，按「层位 + 材料」给每一层贴身份，贴不出身份就停。第二步，用下表取指标串。

| 基层 | 底基层 | 指标串（条数） |
|---|---|---|
| 无机结合料类 | 粒料类 | 二项：稳定层底拉应力、沥青层永久变形 |
| 无机结合料类 | 无机结合料类 | 同上（二项） |
| 沥青结合料类 | 粒料类 | 三项：层底拉应变、沥青层永久变形、路基顶面压应变 |
| 沥青结合料类 | 无机结合料类 | 二项：沥青层永久变形、稳定层底拉应力 |
| 粒料类 | 粒料类 | 三项：层底拉应变、沥青层永久变形、路基顶面压应变 |
| 粒料类 | 无机结合料类 | 三项：层底拉应变、沥青层永久变形、稳定层底的拉应力 |
| 水泥混凝土 | 不设 | 一项：沥青层永久变形 |

补规则三条：季冻区在常规串上追加低温开裂与防冻层；沥青层与稳定层之间夹粒料层时追加沥青层疲劳寿命；沥青碎石类不验算层底拉应力（书里只此一句，未给理由）。

本卡只给「验哪几项」，不给式号与取值：式子在 K4，口径在 K3。指标的力学响应与位置另有表（层底、分层顶面、路基顶面），位置错了式子再对也没用（p329）。

## A1 演练

**【合成演练，非书中案例】**

**第一段（走第一行）。** 结构写作「沥青混凝土面层 + 水泥稳定碎石做基层 + 级配碎石做底基层」。贴身份：基层属无机结合料稳定类，而底基层属粒料类，走表中第一行，指标串两条。此时不做沥青层底拉应变——不是漏了，是这一行的串里没有它。

**第二段（只换底基层）。** 同一套面层与基层，把底基层换成水稳。身份变为「无机结合料 / 无机结合料」，指标串仍是两条且与第一行相同；此时若有人因为「底基层变了」而追加路基压应变，就停在规则之外——该行的串里没有这一项。

**第三段（走第三行）。** 结构是「沥青混凝土 + 沥青碎石做基层 + 级配碎石做底基层」。基层属沥青结合料类、底基层粒料类，走第三行，三条齐全。若有人顺手拿沥青碎石去算层底拉应力，停在参数表那条注上：它被排除在这项验算之外，理由书里没写。

**第四段（只剩一条）。** 结构是「沥青混凝土 + 水泥混凝土做基层」。这一行只剩永久变形一条；若下游仍按稳定层疲劳去排验算项，就停在指标指派这一步——不是算不出来，是这一组合不指派那一项。

## E 执行步骤

**输入契约**：①逐层材料名与层位（面层 / 基层 / 底基层）；②公路等级；③沥青层总厚度；④是否季冻区；⑤沥青层与稳定层之间是否夹粒料层。

1. 逐层贴身份，写成「层位—材料—身份」三列；贴不出身份先停。
2. 取基层与底基层两个身份，查指派表得指标串，写下条数。
3. 核季冻：是则加两项，并把路基湿度状态记下来（防冻是否启动要看它，转 K5）。
4. 核夹层：沥青层与稳定层之间有粒料层则追加一项。
5. 核排除项：串里出现层底拉应力时，看该层是不是沥青碎石类。
6. 把指标串交给 K4 配式子、交给 K3 配口径；本卡不产数值。

**【停判点】**出现下列任一情形必须停下：

- 缺层位身份（只给材料名，说不清是基层还是底基层）→ 停。
- 缺沥青层总厚度 → 停（损坏类型表按厚度分档，档不明则主次关系不明）。
- 基层是水泥混凝土却要求做稳定层疲劳验算 → 停（该组合不指派此项）。
- 季冻区却拿不到路基湿度状态 → 停（防冻层是否启动判不了，转 K5）。

## B 边界

**H1 硬边界（不适用）**：水泥混凝土路面的板厚与接缝设计（另一章的另一套方程）；只问材料级配或配合比、不问层位的题目；改建工程加铺层的层位判定（本章另有加铺内容，不在本表七行内）。

**H2 软边界（降级使用）**：表中「季冻区追加两项」只是指标层面的追加，能不能算出数要看 K5 的闭合度；沥青碎石类的排除项在书中无理由，引用时只能说「书里如此」，不能说「因为某某机理」。
