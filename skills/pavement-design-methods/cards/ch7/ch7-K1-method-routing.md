# K1 方法谱系分流

> 面对一个沥青路面设计任务，先判定手头的数据能支撑哪一套方法、出口要的是分层厚度还是合格判定，并把走不通的那条链在入口处挡回。
> 挂载 verified：f25、p23、p12、p18；背景 reference：f06、f14（只作停判依据，不进执行步骤）
> f25 本身是跨节归并条：六条分流轴逐条有页，但「六轴合起来」不是书里现成的对照表。
> 互引：K3、K7、K2

## R 原文论点

本章把 1958 年以来的五代我国做法与 AASHTO、CBR、AI、Shell 放在同一章里，但每一节只讲自己的推导，没有一张同题同参数的横向对照表；唯一带横向性质的汇总表在转录中整张毁掉，于是「五法对比」只能由读者自己重算（p272–p275、p336）。作者在章末把出口写成验算项的罗列：算出的指标与限值相比，不满足就改结构再算一轮，全书没有反解厚度的通用步骤（p334、p336）。AASHTO 1993 是唯一例外，它把结构数方程、层系数式与逐层分配式都写全了，能从交通量一路解到分层厚度（p286–p291）。CBR 法自带三处结构性缺口：均质体、泊松比取零点五的保守假定、缺交通量这一维、既没有使用门槛也没有损坏门槛（p304）。土基支承值 s 没有测定方法、1986 年起改由回弹模量承担，凡是拿 s 当输入的旧资料都不能进新计算（p292）。

## I 判据骨架

分流靠三根轴，顺序不可颠倒：先看出口，再看输入齐备度，最后看方法自己闭不闭合。

| 轴 | 取值 | 决定什么 |
|---|---|---|
| 出口 | 要分层厚度 / 要合格判定 / 只要路基或材料等级 | 决定能不能走到「出数」 |
| 输入 | 累计标准轴次、路基回弹模量与湿度状态、逐层模量厚度、可靠度、服务性指数差 | 决定走哪一支 |
| 自洽 | 该法内部是否给出「输入→判据→出口」的完整链 | 决定停在哪一步 |

跨节归并出的六条分流轴（不是书里现成表）：①要解方程求厚度 → AASHTO 1993 一支；②要判「这套结构合不合格」 → 我国 17 版验算一支；③只有土基强度与轮载、没有交通量 → CBR 一支，且只能给总厚；④要月损伤累加与动模量 → AI 一支；⑤要反算收敛 → Shell 一支；⑥只有历史资料与实测弯沉 → 只能做校核，做不了设计。

三条硬判据：入口处先问「出口是什么」；方法名与方法口径必须成对出现；任何一条链只要缺一个不可替代的输入，就在缺的那一步宣布停，不许用相邻方法的量顶上。

链条闭合度（这是本卡的核心判据，不是数值）：

| 方法 | 闭合到 | 断在哪 | 页 |
|---|---|---|---|
| AASHTO 1993 | 分层厚度 | 服务性指数差与交通综合偏差无取值规则 | p286–p291 |
| 我国 17 版 | 合格 / 不合格 | 没有反解厚度的步骤 | p334–p336 |
| CBR | 总厚 | 无交通量维度、结构组合另有缺口 | p304 |
| AI | 厚度 | 两个准则各算一厚取大，须程序与诺模图 | p312 |
| Shell | 厚度 | 反算收敛，须程序 | p316–p317 |

〔公式待核〕本卡不引任何计算式；凡下游卡片给出公式处，一律单独标此记号。

## A1 演练

**【合成演练，非书中案例】**

**第一段（走第三支）。** 来人手里只有一份旧路调查：土基 CBR 一串、轮载按轻中重分了档，问能不能直接给分层厚度。按第一根轴，出口要厚度；按第三根轴，CBR 支只闭合到总厚且缺交通量维度。于是走 CBR 支，停在「总厚可给、分层不可给」这一步：缺的是累计轴次与轮压口径，不是缺一个可以估的系数。

**第二段（走第一支）。** 手里有累计标准轴次、路基回弹模量、逐层模量与厚度、可靠度与初终服务性指数，要「最省厚度」。走 AASHTO 1993 那一支，一路可到分层厚度；但若层系数背后的模量不是劈裂回弹模量口径，就停在层系数这一步，先把口径换回来再继续。

**第三段（走第二支）。** 手里是一套已定结构，问「合不合格」。走我国 17 版验算一支；一旦发现基层与底基层的身份没写清（只说材料名、不说层位），就停在指标指派之前——指标串还没定，验算无从谈起。

**第四段（入口即停）。** 只有旧资料里的土基支承值 s，其余全无。停在入口：该量在本章已无测定法、也已被回弹模量取代，任何以它为输入的计算都不成立；此时缺的不是数据，是一个仍然有效的参数体系。

## A2 触发场景

- 「帮我按规范算个沥青路面厚度。」——先问是哪一套规范、哪一代做法。
- 「我们只有 CBR 和交通等级，能出结构吗？」
- 「这份设计文件用的是哪套方法？参数填得对不对？」
- 「五套方法的结果能放一起比吗？」
- 「为什么这本书从头到尾不给一个求厚度的公式？」

## E 执行步骤

**输入契约（要用户提供）**：①出口（厚度 / 合格判定 / 仅定级）；②累计标准轴次及其换算口径（哪个指标、几次幂）；③路基强度表达（回弹模量或 CBR）与湿度状态；④逐层材料与层位；⑤可靠度或服务性指数差；⑥是否季冻区。

1. 先写出口，一句话：要厚度、要判定、还是只要定级。
2. 对照三根轴填表，标出每一格的「有 / 无」。
3. 用闭合度表选支：能到厚度的只有 AASHTO 1993；要判定的走我国 17 版；只有土基强度的走 CBR。
4. 逐项核该支的不可替代输入，缺一项就记一条停判理由。
5. 若用户要跨法对比，先声明「本章无同题同参数对照表」，再各自重算并分别标注口径。
6. 输出去向：能走通的交给下游对应的卡（口径转 K3、指标转 K2、厚度转 K7）；走不通的写明断点。

**【停判点】**出现下列任一情形必须停下，不得估算补齐：

- 出口写的是「厚度」，而所选方法只有验算项 → 停。
- 路基强度只有土基支承值 s → 停（该量已无测定法）。
- 只有 CBR 与轮载、没有累计轴次 → 停（CBR 支无交通量维度）。
- 要跨法对比却拿不出一套共同的轴载与模量口径 → 停（转 K3）。

## B 边界

**H1 硬边界（不适用）**：机场道面与水泥混凝土路面（属另一章的另一套方程）；需要动力响应、温度场或模量反演的题目（属其他章与其他书）；只问材料配合比、不问结构层组合的题目。

**H2 软边界（降级使用）**：仅有 reference 档支撑的判断（如 1958 与 1966 两代的细节）只能当背景，不能作为「该法可执行」的依据；本章一图未得，凡结论依赖读图（CBR 查图、Shell 换温、AI 月模量）的都只能定性。
