# K8 疲劳方程选型与应变量纲

> 先认控制方式与模量口径，再认应变是按百万分之一还是按小数代入；同一符号差一步就是十几个数量级。
> 挂载 verified：f09、c16、ce-A11
> 并入条：p15、p16、p17
> p15 / p16 / p17 三条局部规则按验证小结并入本卡作边界注，不单独成判据。

## R 原文论点

本章把五家疲劳研究并列：英国诺丁汉两条对数式，一条对密级配沥青碎石、一条对热碾沥青混凝土，自变量都是沥青层底水平拉应变（式 7-38、7-39，p278）；同一学派还有一条把拉应变、沥青体积、软化点与作用次数连起来的式子（式 7-40，p278）；伯克利一系进入美国地沥青学会方法的式子含弯拉应变与混合料劲度（式 7-41，p278）；俄亥俄一系走断裂力学，用裂缝扩展律（式 7-42，p279）。17 版另给一条应变型与一条应力型（式 7-111、7-113，p329–330），Shell 用混合料劲度与沥青体积表达疲劳应变（式 7-109，p316）。作者只交代各家的来源与标定对象，没有给「什么情况选哪一条」的规则；对 AI 那条还写明：按该式算出的开裂面积约占总面积两成，且只对标准混合料标定（p308）。于是选型与代入口径都落回使用者身上。

## I 判据骨架

三道闸，顺序固定。

| 闸 | 问什么 | 走错会怎样 |
|---|---|---|
| 一 | 控制方式：应力控制还是应变控制 | 同一混合料两条曲线的斜率不同，寿命不可比 |
| 二 | 模量口径：劲度、动模量、复数模量、还是二十度动态压缩模量 | 各式对模量的负幂次并不相同，口径错则寿命整档偏 |
| 三 | 应变的计量：按百万分之一的数字，还是按小数 | 见下，差十几个数量级 |

**应变量纲陷阱（本卡最要紧的一条，也是全章最危险处）**

同一个物理应变有两种写法：一种是小数，一种是以百万分之一为单位的数字，两者相差六个数量级。对一条形如「对数寿命 = 常数 + 斜率 × 应变对数」的式子，把 ε 换一种写法，应变对数就整体平移六，再被斜率放大：

- 式 7-38 的斜率约为负四点一六，平移量乘上去约二十五个数量级〔公式待核〕，即 **N_f 相差 10²⁵ 倍**。
- 式 7-39 的斜率约为负四点三二，约二十六个数量级〔公式待核〕，即 10²⁶ 倍。
- 式 7-111 与式 7-121 在说明处明写按百万分之一的数字代入（p329、p332）；式 7-38、7-39 一类只写「水平拉应变」、不标计量，只能由量级自洽反推为小数〔公式待核〕——这是反推，不是原文声明。

危险在于：这个偏差不会报错，多数情况下也不会给出负数让你警觉，它给出的往往是一个量级「看着正常」的寿命。所以判据只能是「先读约定，再代入」，不能是「看结果是否离谱」。

**为什么不能互比**：同为应变型，各式对应变的负幂次从二点几到四点几不等〔数值待核原图；口径：本章并列各式，p278–280，见 c16〕，标定混合料、破坏定义（开裂面积比例）与加载方式也各不相同；两条式子算出的次数不能并排放进一张表里比大小。

选型判据（三条，均为「不足以选」时的停判依据，不是选择规则）：①式子自带的标定材料与实际混合料不符 → 不用；②式子要求的模量口径拿不到 → 不用；③式子没有说明 ε 的计量 → 不用。

## A1 演练

**【合成演练，非书中案例】**

**第一段（第一闸）。** 来人手上有两条诺丁汉式与一条 AI 式，问该用哪条。先问控制方式：室内试验是应力控制还是应变控制；再问标定材料是不是同一种混合料。两问答不上来就停——不是选不出，是缺「这条式子在什么条件下成立」的说明。

**第二段（第二闸）。** 选中一条含劲度的式子，手上只有二十度动态压缩模量。停在模量口径这一步：劲度与动态模量不是同一个量，模量项的指数会把差异放大；缺的是同一口径的模量。

**第三段（第三闸·危险段）。** 有人把小数形式的应变直接代进一条按百万分之一写的对数式，算出寿命后写进报告。停在这一步：必须先读说明处的计量约定；此处的偏差是数量级级别，而结果看上去完全正常，所以只能靠「先读约定」拦，不能靠「看结果是否离谱」拦。

**第四段（不可比）。** 两家式子各算一个寿命，被并排放进同一张对比表。停在制表这一步：标定混合料与破坏定义不同，两张表只能各自与自己的限值比，不能互相排名。

## E 执行步骤

**输入契约**：①式号（含页码）；②该式说明处对 ε 的计量约定；③控制方式（应力 / 应变）；④式中所要的模量口径与实测值；⑤标定材料与实际混合料是否同类；⑥破坏定义（开裂面积比例或别的）。

1. 读式子的说明处，先把 ε 的计量抄下来，写在算式上方。
2. 核控制方式与模量口径，两项任一不符即停。
3. 核标定材料：标准混合料还是通用；非标准混合料是否有组成修正系数可用。
4. 代入前做一次尺度检查：把 ε 同时按两种尺度估一下对数值的量级，看哪一个落在合理区间；两个都「合理」就说明约定没读对。
5. 算出寿命，只与该式自己的限值或该指标自己的累计轴次比。
6. 输出时把「式号 + 页码 + ε 计量 + 模量口径」四件一起写，缺一件即视为不可复核。

**【停判点】**出现下列任一情形必须停下：

- 式子的 ε 计量约定读不到（说明处残缺）→ 停。
- 应变给的是小数，式子按百万分之一写，且未换算 → 停。
- 只有动态模量，式子要劲度或复数模量 → 停。
- 混合料是改性沥青，而式子的诺谟图已声明对非常规沥青不适用 → 停。
- 两条式子算出的寿命要排名 → 停（不可互比）。

## B 边界

**H1 硬边界（不适用）**：以应力为控制变量且只给应力比的式子不能拿来算应变形变；只问材料疲劳试验曲线本身、不问结构响应的题目；需要温度场与月损伤累加的场合（属别的方法支）。

**H2 软边界（降级使用）**：AI 那条式的判据本身允许约两成开裂面积，所以它给出的寿命不是「无开裂寿命」，引用时必须带这句限定；p15 / p16 / p17 三条局部规则（两准则取大、非标准料乘组成系数、十倍扩大系数不外借）只能当边界注，不能单独成判据。
