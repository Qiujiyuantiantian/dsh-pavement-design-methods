# K1 先问哪一套

> 一句话：问「能定到几级」之前先问是哪一套；自然区划与沥青气候分区各有一套坐标，章内没有换算，答错也像答对。
> 挂载 verified：p01、f03、f04、p07（四条）；挂载 reference：无。
> 页码一律印刷页（＝源文件页标 − 9）；本章正文落在印刷 99–143。
> 章级纪律：本章两套分区零映射（p100–p102 对 p140–p143）
> 互引：K2、K4、K5、K6

## R 原文论点

本章有两条编号线，都叫「分区」，坐标却不同。

A 线在第二节（p100–p102）。全国按三级切。一级看气候、地理、地貌，切成七块：p100 先把七个大区点成一串名字（原书是连着列的；本卡为指称方便，在每个名字后加一个区字：冻土区、湿润区、干湿过渡区、湿热区、潮暖区、干旱区、高寒区）；p101 换成正式区名，从 Ⅰ 到 Ⅶ 逐区一段，讲各区的主要病害与用料方向。二级改按潮湿系数定，p101 末行与 p102 表块合起来是六档（潮湿系数由年降水与年蒸发之比定义，式 3-1 在 p102）〔公式待核〕。二级区的数量有交代：三十三个二级区、十九个副区（p101）。三级由各省自划，p102 明说没进全国图。用途也分开写：一级服务全国性的规划与设计；二级给各地的设计、施工、养护提供依据与参数，回弹模量、临界高度、压实标准都点了名，值一个没给（p102）。

B 线在第七节（p140–p143）。三个指标各管一个位：高温一位、低温一位、雨量一位；两位号叫温度分区，三位号叫气候分区（拼法与读法在 K2、K3）。用途是选结合料等级、定配合比设计与检验。

两线之间，本章没有一句互通的话，也没有任何换算函数。这是两套坐标并置，不是同一套的粗细两档。

## A1 演练（【合成演练，非书中案例】；零数值结果）

**【合成演练，非书中案例】**本段不出现任何数值结果。

第一段（先反问）。来人问「这条路的气候能定到第几级」。先别报级数，反问两件：这个号拿去做什么——规划与参数，还是选材与配合比？手上有没有区界图？

第二段（走 A 套）。若答「规划用、有区界」。那就只在七个大区里落一个，交付三件：代号、区名、该区要点。若对方接着要二级区，停——本章只有三十三与十九这两个总数，没有名单；拿潮湿系数的那一档顶上去也不行，档是划分指标。

第三段（走 B 套）。若答「选材用」。这一套不要区界图，要三个统计量，能定到两位或三位，往下转题名带「定级」的那张卡。若对方把 B 套说成「比 A 套细一层」，纠正：轴不同、粒度也不同，不是粗细关系。

第四段（拒绝混用）。若来人已经揣着一个两位号，又想拿它去查自然区划的二级区，停：两套之间没有映射，本章也没给过对应表。

## E 执行步骤

**输入契约（要用户提供）**：①这个号服务什么（规划与参数／选材与配合比检验）；②手上有无区界图；③要的粒度（大区／两位号／三位号）；④出口（只要号／号加要点／只判「能不能定」）。

1. 先答「哪一套」，不许跳过这一步直接报级数。
2. A 套：按外部区界落大区，抄代号、区名、该区要点三件。
3. B 套：转 K2，按两个温度或三个指标落格。
4. 交付时写明是哪一套、到第几级；把两级混在一段里写的，退回重写。
5. 要的粒度超出该套能力时，按下面的停判点处理，不估算补齐。

**【停判点】**出现下列任一情形必须停下：

- 要求定出三十三个二级区里的某一个 → 停（无名单、无代号、无区界图，只有总数）。
- 要求定出三级区 → 停（由各省自划，明说未进全国图）。
- 要求把潮湿系数的那一档当区号用 → 停（档是划分指标，不是名单）。
- 要求给两套之间的换算或对应表 → 停（章内零映射、零互指）。
- 要求给二级区的模量、临界高度或压实标准取值 → 停（只点了名，值不在本章）。
- 没有区界图却要求落一个具体地点 → 停（本章只给七个区的代号、区名与要点）。

〔公式待核〕本卡只点名 A 套的定义式（式 3-1，p102），不代值；B 套的拼号是位次拼接，原文没有写成式子。

## B 边界

**H1 硬边界（不适用）**：二级区与副区的名单与代号；三级区划；两套之间的换算；二级区的参数取值（模量、临界高度、压实标准）；具体地点的落区（缺区界图）；把两位号或三位号当自然区划号使用。

**H2 软边界（降级使用）**：四行对照表与「能定到几级」表都是本卡归并的，书里没有这两张表，只能当检查清单、不能当引文；p100 的七个简称与 p101 的正式区名是同一批区的两套叫法（这一点候选已点明，本次核对确认），引用时要么全用简称、要么全用正式名；第七节引用的那本施工规范，本章只给名字，不给条文与取值。
