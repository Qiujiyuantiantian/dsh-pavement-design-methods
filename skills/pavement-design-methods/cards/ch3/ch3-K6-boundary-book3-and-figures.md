# K6 边界卡：与书 3 对账＋图不取数

> 一句话：与书 3 只能对两位温度层（九行四项逐格全同、缺格也同为三格），三位号与自然区划都不可对；本章的图不能当数值来源。

> 章级纪律：跨书引用只到两位温度层；图上读数只作定性（p142、p113–p139）
> 互引：K1、K2、K3

## R 原文论点

两条边界，一条向外、一条向内。

向外那条在 p142。把表 3-18 里三行备注「不存在」的去掉，剩九行。书 3 第 1 章那张表也是九行、四列：代号、区名、高温界、低温界，没有雨量列。逐格比过，四项 9/9 全同，缺的也同为 3-1、3-3、3-4〔机检，非原文〕。两侧还有一处排法差异：本章的高温列纵向合并，书 3 那张每行都填值；值本身不差，排法不同。

向内那条在 p113 到 p139。三十一个图号连续，占位只有十四个（一组版面矩形，没有像素），图题二十二个；九个图号既无题也无位——3-8、3-9、3-11、3-15、3-18、3-21、3-26、3-27、3-31。它们被引用的地方从 p113 一直散到 p138：3-8 与 3-9 在 p113 首见、p114 又提一次，3-11 在 p115，3-15 在 p116，3-18 在 p117，3-21 在 p124，3-26 在 p135 与 p136 各一处，3-27 只见于 p136，3-31 在 p138〔机检，非原文〕。要命的是其中三处正是「要一个数」的地方：3-8 与 3-9 是温度场计算与实测的对比，3-31 是累计度日曲线，也就是取冻结指数的地方。

## I 判据骨架

对账四条边界，逐条有依据：

| # | 边界 | 依据 |
|---|---|---|
| 1 | 只对两位温度层 | 九行四项 9/9 全同；缺格同为三组 |
| 2 | 三位号不可对 | 书 3 那张只有四列，没有雨量维 |
| 3 | 自然区划完全不可对 | 轴不同（潮湿系数加地貌 对 两温度加雨量）；粒度不同（七区／三十三加十九 对 三乘四乘四） |
| 4 | 名称与排法不同、值相同 | 指标名一处叫七月平均最高气温，一处叫最热月平均最高气温；统计量其实是同一个（近三十年里最热月那段的日最高气温，取其均值）；本章合并列、书 3 逐行填 |

缺格一致这条最硬：它能排除「数值碰巧相同」这种解释。

（九行与四列这两个计数〔数值待核原图〕，条件为按 p142 与书 3 那张表的纸面行数点；三十一、十四、二十二、九这四个计数是机检结果，按〔机检，非原文〕处理，不进取值链。）

图这一侧的判据只有一句：凡结论要靠图上读数，本章给不出，只能定性；且不许把占位矩形当图，也不许把图题当图——有题无位的那几张，题在而图不在。

## A1 演练（【合成演练，非书中案例】；零数值结果）

**【合成演练，非书中案例】**本段不出现任何数值结果。

第一段（先降位数）。来人拿一个三位号，问「这个号和另一本书那张表对得上吗」。先截前两位，再看那本书那张表有没有第三列；没有就说明第三位无处可对，只对前两位。

第二段（两类号分开）。若来人拿的是自然区划号，直接说不能对：两边切分用的轴不同、粒度也不同，不是同一张网格的不同版本。

第三段（排法差异要说清）。逐格比对时，本章的高温列是合并的，另一本书是逐行填的；先把合并列填满再比，填的时候不许把空白当零，也不许把空白当「没有阈值」。

第四段（图）。来人又问「能不能从那张对比图里读一个数」。查图号有没有题、有没有位：既无题又无位，只能定性；他坚持要数，停，并说明这三处恰好就是全章最想要数的地方。

第五段（交付）。交付时写清对到第几层、缺哪几格、哪些图不能取数；三件缺一件，退回。

## A2 触发场景

- 「两本书的分区表是不是同一张？」
- 「自然区划和那边的九格表能对账吗？」
- 「图里能不能读出最大温度梯度？」

## E 执行步骤

**输入契约（要用户提供）**：①要对的号是几位（两位／三位／自然区划）；②对方那张表有几列；③要对的项（代号／区名／高温界／低温界）；④要不要读图取数。

1. 先数位数：两位才进对账，三位先截两位再进。
2. 数对方表的列数：四列可对前两位；没有雨量列，第三位无从对起。
3. 填满本章表 3-18 的合并列（只向下填，不补值），再逐格比四项。
4. 记下缺的格：三组代号两边都不列，这一条要写进结论。
5. 图：先查有无题与位；九处无题无位的，一律只作定性。
6. 交付「对到第几层、缺哪几格、哪些图不能取数」三件。

**【停判点】**出现下列任一情形必须停下：

- 拿三位号去和书 3 那张表逐格比 → 停（那边没有雨量这一维）。
- 拿自然区划号去和书 3 对账 → 停（轴与粒度都不同）。
- 要求从图 3-8、3-9、3-26、3-27、3-31 读一个数 → 停（无题无位，只能定性）。
- 把占位矩形当图、或把图题当图 → 停（有题不等于有图）。
- 要求把书 3 那张表的区名当本章区名直接引用 → 停（只到两位这一层可对）。
- 要求补一版新的分区表来「对齐两边」 → 停（本章不承担，且不许写现行表）。

〔公式待核〕本卡不引算式：对账比的是表行与代号，图比的是题与位，两处都没有式子。

## B 边界

**H1 硬边界（不适用）**：三位号对账；自然区划对账；图上取数；用书 3 的区名替换本章区名；补新版分区表；把「九行全同」推成「两张表可以互换引用」（能对账不等于能互换：一边是温度分区，一边是另一套书的分区表，用途不同）。

**H2 软边界（降级使用）**：9/9 逐格比是本次在本仓库的转录件上机检的〔机检，非原文〕，书 3 那一侧没有回原书版面图，所以这条结论的效力止于「转录件之间一致」；「三十一个图号、十四个占位、二十二个图题、九处无题无位」同样出自机检，且占位只有版面矩形、没有像素，所以连「图在不在」都只能按坐标判，不能按内容判；「指标名不同而统计量同」是本次的判断〔推断〕，两边原文只各给了一句取法，没有互指。
