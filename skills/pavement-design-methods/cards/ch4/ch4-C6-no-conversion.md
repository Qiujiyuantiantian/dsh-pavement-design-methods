# C6 不能换算：五处用「或」连起来、实际互不配套

> 挂载 verified：p15、f05、p16、p12、p03（5 条）
> 互引：C2 条件四问｜C3 取值基准（76cm 与 75cm）｜C7 折减表｜C9 横移量取不到
> 一句话：本章唯一能当场证伪、且不依赖原图的地方就在这里——两条写着「或」的式子，指数对不上。

## R 原文论点

本章有一组式子，用「或」连起来，读起来像同一件事的两种写法。实际互不配套。五处：

**一、4-11（p150）与 4-12（p151）。** 把两式都改写成 K 关于 E₀ 的幂次：前者是三次根，落 2/3；后者是四次根，落 4/3〔复算，非原文〕。真要互逆，两个幂次应当落在 2/3 与 3/2 上；给出的两条都不落 3/2。所以它们不是同一关系的两种写法，只是两条都叫「E 与 K 的换算」。
顺手记一句：有的二手材料把这个指数写成 1.5。1.5 是 4-11 自己反解 E₀ 得到的幂次，与 4-12 不在同一坐标上；把两次反解对举，就等于把方向混在一起。

**二、4-15（p151）。** 左端是 MPa/m 的 K，右端是 CBR 的百分数除以四再加一，两边量纲不齐；而且这条按 75cm 板给出（据日本学者），与 76cm 标准板那套折算不是一条线。原文自己只说用两种指标算厚度相差约 ±1cm，那是个近似程度的说明，不是换算精度的保证。

**三、4-13 与 4-14（p151）。** 前者是系数乘 CBR，系数跨 2~11；后者是 8.9 乘 CBR 的 0.85 次方〔数值待核原图：两条都是他处回归，条件分别为「很多国家的学者」「我国现场试验」，CBR 状态未注明〕。两条相差数倍。更要紧的是 CBR 该取室内饱水值还是野外现场值，全章没交代——而 p150 刚说完两者受侧限与湿度影响并不一致。

**四、提级倍数（p149）。** 混凝土路面下的土基模量要提一定倍数，倍数全章无值。这不是「忘了抄」，是原文只给动作不给数。

**五、S(t,T)（p157）。** 温度与加荷时间对劲度的影响可以互换，这是原文明确写的性质；但换多少、按什么函数换，没有给。可以互换的效果，不等于可以换算的系数。

五条指向同一句话：**两边叫同一个名字，不等于可以对接。**

## A1 演练

**【合成演练，非书中案例】**

第一段（互校）。来人拿一条式子反解出 E₀，再用另一条式子正算回去，看能不能对上。判：两式幂次不配套，校核不成立，停。

第二段（并列）。来人拿按小板径给的那条经验式，要与标准板那条并排放进一张表。判：量纲不齐、板径不同，停。

第三段（取平均）。来人把两条 CBR 反算的结果各算一遍，要取平均。判：CBR 状态未定，两条相差数倍，平均没有意义，停。

第四段（要倍数）。来人要混凝土路面下的提级倍数。本章无值，停。

第五段（挪曲线）。来人要把一个温度下的时间曲线挪到另一个温度。横移量未给，停，转另一张卡。

第六段（指数抄错）。来人报了一个从别处抄来的指数，说「按这个对举就行」。指出那是另一方向反解得到的幂次，与另一条式子不在同一坐标；本卡的指数对另写，不许拿它校核。

## E 执行步骤

**输入契约（要用户提供）**：①要换算的两个量；②各自的板径与状态（软／硬、饱水／现场）；③式号与印刷页；④用途（估算／互校／进计算）；⑤若涉及 S，另要温度与加荷时间。

1. 判两式是不是同一条关系的两种写法：写出两式各自解出的幂次或量纲，对不上即判「并列不互逆」。
2. 查量纲：两端单位是否同类；不同类只许当经验近似。
3. 查板径与状态：75cm 与 76cm、饱水与现场，任何一项不同即不可并列。
4. 查系数是否他处回归：是，则标注来源，不与本章实测混排。
5. 查有没有给倍数或横移量：没给即停，不许自取。
6. 输出：可换算／只能估算／停＋理由一句话。

**【停判点】**出现下列任一情形必须停下：

- 两式指数或量纲对不上仍要求互校 → 停。
- 量纲不齐仍要求写等号 → 停。
- CBR 状态（室内饱水／野外现场）未定 → 停。
- 要混凝土路面下的提级倍数 → 停（本章无值）。
- 要 S 的温度—时间横移量或函数 → 停（转 C9）。
- 要求「按 1.5 对举」→ 停（指数是 2/3 与 4/3；1.5 是另一方向反解的结果）。
- 拿 4-15 的结果去乘 76cm 的折算系数 → 停（板径不同）。

## B 边界

**H1 硬边界（不适用）**：把「或」读成「等价」；给 4-11／4-12 补第三条式子来弥合；用 1.5 与 4/3 对举；给提级倍数自取一个值；把 4-15 折到标准板口径；把「相差 ±1cm」当换算精度的保证。

**H2 软边界（降级使用）**：幂次是对式体做根次改写得到的复算结论，随式体版本变；4-13 的系数区间与 4-14 的两个常数都是别人回归，本章只转述，不担保。两式「相差数倍」是量级说法，不给倍数。
