# C9 试验能做，系数取不到

> 挂载 verified：f06、f08、f10、f14、p17（5 条）
> 背景 reference：f02、f11、f12、f13（四条都是「动作那一步缺输入」，只作停判例，不单独成卡）
> 互引：C2 条件四问｜C5 三种模量｜C6 不能换算｜C8 混凝土的空位
> 一句话：这一章的交货是**协议**，不是**系数**；把协议读成系数表，就会在最后一步凭空造一个数出来。

## R 原文论点

本章把五类试验的做法写全，系数一个不给。

**一、累积变形。** 4-2 与 4-3 是同一条幂律的两种写法，可互相推出（p146）；η 被称为统计的回归系数，没有值。同页还有一串相对荷载的界：较干土在一个区间内重复作用会固结硬化，偏湿以后黏性土、砂性土、粉性土各有一个更小的安全界〔数值待核原图：条件是「相对含水率分别低于与高于 0.7、0.7~0.8」两档，界以相对荷载表示〕。这是观察值，只能判落在哪一侧。

**二、剂量—强度。** 常用剂量段内大致是直线、线有穿过原点的倾向、一年以后这条关系仍在（p153）；改善级配能把所需剂量降下来（原文举天然砂砾与最佳级配砂砾的对照）。三条约束同在两页：基层剂量不许过 6%、有的国家卡 5%；均匀系数宜大于 5、最好大于 10；塑性指数宜小于 12（p152–153）。但斜率没有，所以只能答「往哪个方向改」，不能答「改到几个百分点」。

**三、稳定材料弯拉疲劳。** 协议齐：先测弯拉强度，再按应力比（重复应力对极限强度之比）做，推荐区间 0.5~0.85；低于 50% 可承受无限次；方程有双对数与单对数两种形式（p156）。但 a、b 两个回归常数一个没有。

**四、抗剪。** 摩尔-库仑式在 p161；侧压取 0、1.45、2.9 kPa；试件直径要大于集料最大粒径的四倍、高径比不小于二、最大粒径小于 2.5cm 时常用直径 10cm 高 20cm（p162）。c 与 φ 的数值全章没有。

**五、沥青。** 劲度式 4-16 带 (t,T) 下标（p157）；查劲度要三个输入（加荷时间、温差、针入度指数），三项都不是材料常数（p158）；沥青劲度高过某个分界时，混合料劲度是沥青劲度与集料数量、沥青含量的函数；低于分界则集料骨架主控（p158）。同页有个陷阱：判据的分界是 10MPa，而壳牌做试验选用的沥青是「劲度大于 5MPa」的，两个数并排——**一个是判据，一个是选材范围**（新发现第 1 条）。疲劳方程 4-18／4-19 的 K 与 C 全无；厚度分界（厚面层下限 15cm、薄面层上限 5cm）在 p160，三项放大（间歇、裂缝扩展、轮迹分布）同在 p160，但放大那三项原文标着「据观测分析」「据估计」。

**四条 reference 正是这一层的四个实例**：f02（1mm 归纳只有名字、提级倍数无值）、f11（时间温度等效只到「能重合」，横移量与函数都没有，图 4-14 只有一次提及、无位无题）、f12（两张诺谟图只有图题、没有等值数表）、f13（四个常数全无，能落地的只剩「先定模式」，已由 p17 承担，不另立卡）。

## I 判据骨架

| 试验 | 能做到哪一步 | 缺的那一格 | 停在哪 |
|---|---|---|---|
| 累积变形幂律 | 两式互推、可拟合 | η | 不能外推次数 |
| 剂量—强度 | 判方向、判上下限 | 斜率 | 不给百分点 |
| 稳定材料弯拉疲劳 | 协议齐全 | a、b | 不算寿命 |
| 抗剪 c、φ | 规程齐全 | 两个数值 | 不给参数 |
| 沥青劲度 | 三个输入齐 | 诺谟图数表 | 查不了图 |
| 沥青疲劳 | 方程形式齐 | K、C | 不算寿命；三项放大不当系数 |

〔公式待核〕4-2、4-3、4-16、4-18、4-19、4-20 均只作定位，不引式体。

## A1 演练

**【合成演练，非书中案例】**

第一段（外推次数）。来人要按幂律把短期变形外推到更多次数。缺 η，停。

第二段（反求剂量）。来人要按直线反求「剂量能降到几个百分点」。缺斜率，只给方向。

第三段（算寿命）。来人要算稳定材料的弯拉疲劳寿命。缺两个回归常数，停。

第四段（取参数）。来人要 c 与 φ 的数值。规程有、数没有，停。

第五段（查图）。来人要按诺谟图取混合料劲度。图只有图题、没有等值数表，停。

第六段（放大）。来人要把三项放大乘进寿命式当换算系数。原文那三项标着观测与估计，停。

第七段（阈值当容许值）。来人要拿分土的相对荷载界当容许荷载。判观察值，只回方向。

## A2 触发场景

- 「按这个幂律，十万次之后的变形是多少？」
- 「水泥剂量能不能从六个点降到四个点？」
- 「稳定基层的疲劳寿命怎么算？」
- 「c 和 φ 取多少？」
- 「诺谟图帮我查一个劲度。」
- 「室内寿命乘几倍就是现场寿命？」

## E 执行步骤

**输入契约（要用户提供）**：①哪一类试验；②试验参数定了没有（应力比、侧压、温度、加荷时间）；③要的是「出数据」还是「算结果」；④缺的那一格能否在别处找到；⑤出处印刷页。

1. 判是「做」还是「算」：做，章程照抄即可；算，先查系数在不在。
2. 逐列查系数：η、斜率、a 与 b、K 与 C、c 与 φ、诺谟图数表。
3. 缺系数而用户仍要结果的，判停，并说明缺的是哪一格。
4. 涉及分土阈值的，判观察值，只回答落在哪一侧。
5. 涉及三项放大的，判「观测或估计」，不许当换算系数。
6. 遇到只有图题的诺谟图，判不可查；图 4-14 连图位都没有。
7. 输出：能出数据／不能出结果＋缺的那一格＋若停则给出可做的替代（改做哪个试验）。

**【停判点】**出现下列任一情形必须停下：

- 缺回归系数却要结果 → 停。
- 要求用「大概的系数」或工程经验值 → 停（不许自取）。
- 查图而无数表 → 停。
- 拿分土观察阈值当容许荷载 → 停。
- 拿三项放大当换算系数 → 停（原文标着观测与估计）。
- 要求把四条 reference 当步骤执行 → 停（它们缺的正是输入）。
- 要求把 10MPa 判据与 5MPa 选材范围合成一个门槛 → 停。

## B 边界

**H1 硬边界（不适用）**：自取 η、斜率、回归常数、c 与 φ；把图题当数表；把研究性结论当设计依据；把三项放大乘进寿命式；把观察阈值当容许值；替四条 reference 补它们缺的输入。

**H2 软边界（降级使用）**：「能做」指照协议能出数据，不等于出的数据能直接进设计；系数缺失是本章的缺项，不是判它不成立。研究性结论只能当方向。清点与页号随版本变。
