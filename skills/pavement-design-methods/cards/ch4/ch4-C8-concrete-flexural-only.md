# C8 混凝土只认抗折，门槛只判越界

> 挂载 verified：p04、f15、f16、p06（4 条）
> 互引：C1 数有三种（门槛是第三类）｜C2 条件四问｜C6 不能换算｜C9 试验能做、系数取不到
> 一句话：这一节不是「参数表」，是「指标次序＋验收门槛＋两个空位」；空位比门槛更值钱。

## R 原文论点

第四节分两个小节（p163–172）：前一小节讲混凝土性能，后一小节讲表面使用品质。材料侧的交货都在前一小节，只有两样。

**一、第一指标是抗折。** 路面与机场道面用混凝土认抗折，抗压只作参考（p164）；抗拉远小于抗压，原文给的量级是抗压的十分之一到二十分之一。原因在加载方式：抗折取决于抗拉，抗拉看匀质性与界面的黏结；抗压走压剪，对匀质性和界面强弱没那么敏感（p165）。所以拿抬抗压的办法去抬抗折，常常不奏效，甚至反向。

七项因素（水泥、粗集料、砂细度模数、单位水泥用量、水灰比、单位用水量、含气量）逐项比对后，**唯一的反向项是含气量**：抗压单向下降，抗折先升后降（p166）。但原文只说「有些恰恰相反」，没有点名落在哪一项——这一句要写成本卡自己的比对结论，不能记成书里的指定（按 E9）。

**二、抗折有两个值。** 设计抗折强度 5MPa（p167）；施工配制抗折强度 5.5~5.75MPa，最小 5.5MPa（p165）〔数值待核原图：条件是「高速公路、一级公路；混凝土施工配制」，单位 MPa〕。原文只说「设计抗折强度」，没说它是算板厚那处专用的（按 E10）。按交通量分级给的计算抗折强度要求，只有一句引用、**没有表体**（p164）。

**三、门槛四条。** 含气量、最大水灰（胶）比、最大单位用水量、最小水泥用量，成组出现在耐久性那一小节（p170），口气全是上限或下限。另有细集料与粗集料的含土量、针片状、压碎值一类工地控制值散在前一节（p165）。

**四、两个空位。** **E_c 与抗折疲劳方程，本章为 0。** E_c 三个字母全章只出现在 4-11、4-12 与符号表里（p150–151），第四节一次未提；抗折疲劳只有研究性结论（粗集料粒径与粒形、游离氧化钙、含气量三路，p166–167），没有方程、没有常数。另有两条容易误推：混凝土板的泊松比给了 0.15（p151），但它只服务那两条互不逆的换算式；土的泊松比是 0.3~0.5（p145）〔数值待核原图：前者条件是「混凝土板」，后者是「土」，同符号两材料〕——按符号取会差一个量级。

所以 ch8 那把 D／J／Cd／Ec／K 里，**Ec 这一格在本章是空的**；本章也没有抗折疲劳方程可交。这不是「第四节不完整」，是这一章根本没打算交这两样：它交的是指标次序与验收门槛。

## A1 演练

**【合成演练，非书中案例】**

第一段（要 E_c）。来人要混凝土弹性模量进板厚计算。本章没有这一格，停；不许从换算式反解出来当材料参数。

第二段（要疲劳方程）。来人要抗折疲劳方程算寿命。本章没有这一格，停。

第三段（抗压推抗折）。来人拿抗压等级推抗折。原文给的量级是抗拉对抗压，不是抗折对抗压；判不可推，停。

第四段（门槛当能力）。来人把耐久性那一小节的数当「混凝土能达到的水平」。判第三类，只回答越界与否。

第五段（分级要求值）。来人要按交通量分级的要求值。只有一句引用、没有表体，停。

第六段（符号混用）。来人拿混凝土板的泊松比去算土基。同符号不同材料，停。

## E 执行步骤

**输入契约（要用户提供）**：①要哪一样（抗折／抗压／E_c／疲劳方程／某条门槛）；②用途（配比／判越界／算板厚／算寿命）；③交通量等级；④出处印刷页。

1. 判要的是「交的」还是「没交的」：先对 I 段两张表。
2. 是 E_c 或疲劳方程：直接判空位，不给替代。
3. 是抗折：分清设计值与施工配制值，并写明是哪一个。
4. 是门槛：只做越界判断，输出「越／未越」，不给能力值。
5. 是分级要求值：指出只有一句引用、没有表体。
6. 涉及泊松比：先认材料，再取值。
7. 输出：能答／不能答＋不能答的是哪一格＋若属比对结论则注明「本卡比对，非原文点名」。

**【停判点】**出现下列任一情形必须停下：

- 要 E_c → 停（本章为 0）。
- 要抗折疲劳方程或疲劳常数 → 停（本章为 0）。
- 要按交通量分级的要求值表 → 停（无表体）。
- 拿抗压推抗折 → 停。
- 拿门槛当能力值或目标值 → 停。
- 拿 4-11／4-12 反解 E_c 当测定值 → 停。
- 把含气量那个反向项说成原文点名的 → 停（须注明是比对结论）。
- 把 5MPa 说成算板厚专用 → 停（原文只说设计抗折强度）。

## B 边界

**H1 硬边界（不适用）**：给 E_c 补值；拿别章或现行规范的抗折疲劳方程来填；把门槛当目标值；把「有些恰恰相反」点名为含气量而不注明是比对结论；把 0.15 用在土基上；把设计值与施工配制值混成一个。

**H2 软边界（降级使用）**：七项因素的相对幅度是原文的试验归纳，不给函数；抗折疲劳那三条只是研究方向，只能当方向。**范围要说准**：本章不是「材料参数值 0 处」——泊松比有三个量、二灰系有若干实测；准确说法是「E_c 与抗折疲劳方程 0」。到 ch8 进判据时，「抗折为第一指标」只是一条次序判断，还要配该章自己的分档与系数，本章不提供。
