# C7 双后轴：定倍数与逐点算

> 沥青侧化简完，双后轴等于单轴的一点三八倍，是个定倍数；水泥侧化简完多出一项二的幺点六八次方，等式不闭合，只能按荷位、板厚与模量比逐点算。
> 挂载 verified：p05、f14、f03、f05
> 互引：C2（指数）、C6（另一处同名）、C5（列错位的归类）

## R 原文论点

**沥青侧。** 使用性能衰变式（2-14，p65）里，轴数 $L_0$ 单后轴取 1、双后轴取 2。把双后轴代进去，$L_0$ 在式内的两个幂次位置要提出一个二的幂；因为 $\beta_{2x}$ 与 $\beta_x$ 化简后相等，双后轴那一式的括号内两项与单后轴完全一样，只剩一个常数：4.79 减 4.33 再乘二的对数，即 $\lg 1.38$〔公式待核〕。于是式 2-21（p66）给出双后轴等于其单轴的一点三八倍〔数值待核原图；条件：单后轴为标准、全部结构数、沥青那一套口径，p66〕。这一步是代数，不是经验约定。

**水泥侧。** 板厚进了指数（式 2-26，p70）。$(P+L_0)$ 的 5.20 次与 $L_0$ 的 3.52 次，双后轴时相除得二的幺点六八次方〔公式待核〕（p71 印出了这条代数）。因此 $\beta_{2x}$ 与 $\beta_x$ 不再相等，双后轴的换算式化简后等式不闭合，书里只留一句「都与厚度有关」。要往下走，只能回到 δ 的定义式 2-64（p79），按荷位、板厚、模量比与轴重逐点算。

δ 的表是表 2-19（p80）：声明六列，实际 60 kN 那行九个数、130 kN 那行十个数，逐格验算做不下去；正文取两个荷位平均，板中 0.23、板边 3.80〔数值待核原图；条件：后轴重 60~130 kN、板厚 19~23 cm、模量比三档，p80〕，同表 δ 的跨度 0.157 到 5.925。

**一处内部不一致要记下来。** 式 2-27（p70）印的是 3.28，而 p71 的双后轴推导里用的是 3.38，差 0.10〔数值待核原图；条件：同一式的 L₀ 幂指数在推导与成式两处印刷不一致，p70–p71〕，落在同一条链的相邻两步。这不影响「双后轴不能给定倍数」这个结论，但它说明这条链在书里本身没有对齐。

**结论分岔。** 沥青侧可以给一个定倍数，水泥侧不行：δ 既有大于一也有小于一，板边受荷时双后轴应力多高于单后轴，板中相反，只在模量比与板厚都很大时例外。这里正是三类缺陷第三类的现场——列错位既不是原书错值，也不是转录丢行。

## I 判据骨架

两侧并列，一句一判。

|  | 沥青侧 | 水泥侧 |
|---|---|---|
| 指数里有什么 | 结构数 | 板厚 |
| 双后轴代进去，化简后 | β 相等，括号内两项抵消 | 多出二的幺点六八次方，不闭合 |
| 结论形态 | 定倍数一点三八 | 逐点算 δ；板中 0.23、板边 3.80 为平均值 |
| 输入需要什么 | 单后轴标准与结构数 | 荷位、板厚、模量比、轴重 |
| 能不能逐格复核 | 能（代数一步） | 不能（列数与声明不符） |

两条使用判据：

1. **先认路面类型，再谈倍数。** 把沥青侧的一点三八搬进板厚体系，或用水泥侧的 δ 去乘沥青侧的单轴换算，都是换了一个问题。
2. **水泥侧的 δ 只能整取一个荷位平均值往下走一步**，且必须写明它覆盖的轴重与板厚区间；区间之外即不可用。

## A1 演练

**【合成演练，非书中案例】**

**第一段（把定倍数搬到板厚体系）。** 来人在水泥路面上也用一个固定倍数把双后轴折成单轴，理由是两个体系「都是轴载换算」。停在类型上：板厚进了指数，化简后括号内两项不再抵消；那一步代数在水泥侧不成立。

**第二段（想把水泥侧也做成定倍数）。** 有人见二的那一项是个常数，就说「那也是个倍数」。停在这一步：它只是化简过程中掉出来的一项，等式两侧并不闭合；书里给出的原话是「都与厚度有关」，那正是不能给固定值的说法。

**第三段（逐格验算）。** 来人想按表逐格取 δ 算个精确值，数完发现一行多出三个数。停在列错位：这张表逐格对不上，只能用两个荷位平均值，并写明覆盖面。

**第四段（相邻两步的差）。** 有人发现同一条链上相邻两页的系数差了一点，就问是不是抄错。停在这里：差落在同一条链的相邻两步，属于内部不一致，不是转录问题；它不动摇「不能给定倍数」这个结论，但不能拿它当推导依据。

## E 执行步骤

**输入契约**：①路面类型（沥青或水泥）；②轴型（单后轴、双后轴及其轴重）；③沥青侧另需结构数；④水泥侧另需荷位、板厚、模量比，以及该轴重与板厚是否落在表 2-19 的覆盖区间内。

1. 认路面类型，选一侧，不许两边混用。
2. 沥青侧：确认标准轴与结构数，直接用式 2-21 的定倍数。
3. 水泥侧：先看双后轴化简后是否闭合；不闭合就不许给固定倍数。
4. 水泥侧继续：取荷位（板中或板边），查 δ 的定义式 2-64，需要时用表 2-19 的平均值。
5. 核覆盖面：轴重与板厚是否落在 60~130 kN、19~23 cm 的区间内；出了区间即停。
6. 输出「类型—轴型—倍数或 δ—覆盖面—页」，交给 C2 与水泥那一支的下游。

**【停判点】**出现下列任一情形必须停下：

- 拿沥青侧的定倍数去算水泥路面的双后轴 → 停（那一侧的化简不闭合）。
- 水泥侧要求给一个与板厚无关的固定倍数 → 停（δ 随板厚与模量比变）。
- 想按表 2-19 逐格取 δ → 停（列数与声明不符，只能取荷位平均）。
- 轴重或板厚超出表的覆盖区间却仍用表内平均值 → 停。
- 拿式 2-27 与双后轴推导里那两个不等的系数互推 → 停（同一条链内部未对齐）。

## B 边界

**H1 硬边界（不适用）**：把双后轴折算推广到三联轴（本章的经验倍数与 δ 都只对双后轴给出）；替读者裁定板中与板边该取哪一个（取决于临界荷位，不在本卡）。

**H2 软边界（降级使用）**：δ 的荷位平均值覆盖面有限，出了 60~130 kN 与 19~23 cm 就不可用；一点三八这个倍数属本书所据的版本，换版本必须重核；表 2-19 的列错位与 $d$ 缺值同属第三类缺陷，处置见 C5，不许当成可以逐格复原的表。
