# C2 指数口径：四值五义

> 「四」附近的指数不是一个数，是四个值、五个义，另有一个十六。每认一个值，必须同时说清三件事：对哪个设计指标取幂、以哪个轴重当标准、在哪一页。
> 挂载 verified：p01、p03、p06、p17、f03、f07；补：4.35（出自 verified 第三节判据 1，两条候选文件里此值零次）
> 反例 reference：p02（把这一族写成三个数，作反面样本）
> 互引：C6（两个 b 不可互验）、C7（双后轴）、C1（链条上谁用它）

## R 原文论点

本章给这些指数时不加限定语：式 2-20（p66）写 4.2，式 2-44（p73）的疲劳式里是 3.97，式 2-53 与式 2-74（p76、p93）写 4，式 2-54（p77）也写 4，而 p66 正文与 p86 的环道折算用的是 4.35。四个值散在五页上，各自的适用对象、标准轴重与单位制都不同，书里从来没有把它们并排列过一次。

逐条回核，五个义如下。

- **3.97（p73）**：疲劳寿命式（2-44）对应式（2-43）时取的 $k_2$，同句还有 $k_3$=1.58〔数值待核原图；条件：沥青混合料疲劳式，应变与模量双幂，p73〕。它不涉标准轴载，是材料疲劳关系里的应变幂。
- **4，义一（p76、p93）**：2017 版的分指标换算系数。拉应变与永久变形取 4，路基压应变取 5，稳定层拉应力取 13〔数值待核原图；条件：三个设计指标各一套，标准轴载 100 kN，p76 与 p93 各印一次〕。
- **4，义二（p77）**：混凝土一侧的换算式（2-54），以 18000 lbf 为标准轴、以服务性指数（2.5 或 2.0）为等效指标〔数值待核原图；条件：英制标准轴 18 klbf，PSI 口径，p77〕。
- **4.2（p66）**：沥青单后轴的回归平均。p66 先给两个耐用性指数档下的平均值 4.3 与 4.05，再平均成 4.18，取整后写进式（2-20）；标准轴是 22 klbf，即 100 kN〔数值待核原图；条件：单后轴、22 klbf 标准、全部结构数参与平均，p66〕。
- **4.35（p66 与 p86）**：我国弯沉等效用的指数。p66 一句把它挂在「新规范」名下，并说是在前述平均值基础上经广泛调查与弹性体系分析得来；p86 的环道实载折算按「弯沉等效的 4.35 次方」把四十余万公里折成约三百七十万次 100 kN 标准轴载〔数值待核原图；条件：100 kN 弯沉等效口径、环道实载、累计里程与轴重构成见 p86〕。它跟 p76 的 4 不是同一义：一个管弯沉，一个管分指标。

另有一个十六（p79、p95）：混凝土单后轴换算取十六次幂。来路是 p77 的室内小梁回归式（2-57）里的 19.115，乘 p78 表 2-16 的 $n$ 均值 0.835，得 15.96〔复算，非原文〕，取整成 16。它和义二那个四同属混凝土一侧，却分属两条来源：一条按服务性指数，一条按室内疲劳回归。

**两个必须防的诱饵。**

其一，4.2 在本章出现五次，只有一次是幂：p65 与 p70 的 $C_0$（完工时的耐用性指数，两页各一次）、p93 表 2-23 的轴组系数（路基压应变指标下双联轴那一格）、p94 表 2-25 的类系数（第 4 类车非满载）。后四次都是别的东西，拿它们当幂必错。

其二，3.97 出现三处，两处是幂、一处不是：式（2-44）体内一处、紧接的 $k_2$ 一句一处，第三处落在 p75 表 2-13 的变异系数列（$E_3/E_2$=0.20 那一行），单位是百分数，与疲劳式无关。

**骨架只有一个。** 本章每一支的换算式都能写成同一个形态：次数比等于两个轴重之比的幂〔公式待核〕，$N_1/N_2=(P_2/P_1)^{\alpha}$；四支路的差别只在于把 $\alpha$ 换成各自的写法与取值。所以「指数取几」这个问题，先要问的是「哪一支、哪个指标」。

**幅度检查（p17）**：指数可以当常数用，但先看它在样本里怎么摆。p69 给出等效系数的全距 4.232~4.638（差 0.436）与指数 $b$ 的全距 0.846~0.928（差 0.082）〔数值待核原图；条件：$p_t$ 取 2.0 与 2.5 两档、结构数从 1 到 7、轴重 120~200 kN，p69〕；p76 又把 1.713 与 1.818 平均成 1.77、最终统一取 1.74，把 0.86 与 0.906 平均成 0.88，把 0.83 与 0.86 取 0.86〔数值待核原图；条件：弯沉支取两值平均后统一、拉应力支取多层体系那一值，p76〕。反例一侧是 p80 表 2-19 的 δ，跨度 0.157 到 5.925，同一个「常数」在那里根本压不住。书中没给「多小算足够小」的阈值——这是停判点，不是缺陷。

## A1 演练

**【合成演练，非书中案例】**

**第一段（拿完工指数当幂）。** 来人在符号表里找「四附近」的数，见它与指数排在同一页，就填进了换算式的幂位。停在「对谁取幂」这一问上：那一栏描述的是完工时的路面状态，不是轴载比的幂。

**第二段（拿变异系数当幂）。** 有人从一张统计表里挑出与疲劳式相同的数字，直接搬进幂位。停在单位上：那一列标的是百分数，与应力比的幂不同量纲。

**第三段（两个四打架）。** 两个人各引一个四，一个说标准轴是英制十八千磅，一个说是一百千牛，同一份报告里两处结论对不上。停在这一步：两个四各自绑着不同的标准轴与不同的等效指标，先分别写清再谈取舍。

**第四段（四点三五与四）。** 来人说「都是新规范的数，取哪个都行」。停在指标上：一个管弯沉，一个管分指标验算；换了指标，同一个车队算出的当量次数就不同。

**第五段（常数当不当得成）。** 有人把某份样本回归出的指数直接拿去算另一批轴重，理由是指数「本来就是常数」。停在幅度检查：先看这一族在该样本里的全距，全距大过待算的差别时，常数化这一步本身要打问号。

## E 执行步骤

**输入契约**：①要用的换算式或疲劳式（式号）；②该式所属的方法与版本；③被换算或被取幂的设计指标；④标准轴重及其单位制；⑤若要做常数化，另需该指数的样本全距（最大、最小与样本条件）。

1. 先认指标：这一幂管的是弯沉、拉应力、拉应变、压应变，还是服务性指数；指标不明先停。
2. 再认标准轴：公制一百千牛、英制十八千磅、英制二十二千磅，三者不许互换。
3. 查表 A 定值，同时把「对谁取幂 / 标准轴 / 页」三项抄下来，缺一项即不可复核。
4. 查表 B 排雷：待用的数字若是 4.2 或 3.97，先确认它在原文里是不是幂。
5. 判要不要常数化：取该指数的全距，与待算的两个轴重之差比一比；全距压不住就停。
6. 输出「值—义—标准轴—页」四列，交给 C6 与 C7 使用。

**【停判点】**出现下列任一情形必须停下：

- 只说「取四」而说不清是分指标那一义还是英制标准轴那一义 → 停。
- 把 4.2 的 $C_0$、轴组系数或表 2-25 的类系数当成幂 → 停（同形不同义）。
- 把 3.97 当换算指数使用 → 停（它是疲劳式的应变幂，见 C6）。
- 要跨标准轴比较（十八千磅对一百千牛）却拿不出一套统一换算 → 停。
- 要做常数化，却给不出该指数的全距与样本条件 → 停（p17 的检查没有输入）。

## B 边界

**H1 硬边界（不适用）**：替读者裁定「哪一条该用于设计」——本章给了两组并存的口径，没有一句裁决；把本章的指数直接当现行规范条文引用；由指数反推疲劳方程的系数（系数在 ch7 的疲劳式里）。

**H2 软边界（降级使用）**：4.35 的出处只有 p66 一句加 p86 一个实例，没有推导、没有适用范围说明，引用时只能写「书中如此」；4.2 的 4.18 是平均值取整，取整前后的差落在小数点后第二位，别在小数位上做文章；十六次幂的 15.96 是复算，原文只有 19.115 与 0.835 两个因子，复算值不许冒充印刷值。
